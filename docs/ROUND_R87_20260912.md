> 规则：每完成一轮改进即重新基线并产出**下一编号**的规划。本轮（R87）执行 P416：**标准型材规格表**。
> 交付：`scdm/beams.py` 增加 12 条标准规格（工字钢/等边角钢/圆管/扁钢，公称尺寸按 GB/T 706/3091/704），
> 规格名可被 op 直接使用并写进实体名；验收用**独立算法**（矩形分解 + 平行轴）与**实测几何**（体积、截面特性）双向对拍。

## 1. 规格表（公称尺寸，mm）

| 截面 | 规格 | 尺寸 |
|---|---|---|
| 工字钢 `i` | I10 / I12.6 / I16 / I20a | h×b×tw×tf = 100×68×4.5×7.6 … 200×100×7×11.4 |
| 等边角钢 `l` | L50x5 / L63x6 / L75x8 | a×b×t |
| 圆管 `pipe` | D60x3 / D76x4 / D89x4 | d×t |
| 扁钢 `flat` | FB40x10 / FB50x12 | b×h |

**口径写明在注释里**：本模块的截面是精确多边形（无圆角），所以闭式值与手册里"含圆角"的数值有约 1% 的系统差（圆角补料）；
登记的是**公称尺寸**，测试对拍的是**自洽性**而不是手册数字。

## 2. 接口

| 函数 | 作用 |
|---|---|
| `B.spec_names(profile=None)` | 规格名列表（可按截面过滤；未知截面报错并列出可选项） |
| `B.spec_dims(name)` | → `(profile, {参数: mm})`；未知名报 `K.KernelError` 并列出可选项（拼错不会变成"凭空截面"） |
| `B.named_spec_label(name)` | `工字钢 I 160×88×6×9.9（I16，GB/T 706）` |
| `op create.beam` 的 `opts["spec"]` | 用规格名建梁（与手填尺寸二选一），实体名即上式的标签 |

## 3. 验收（每条都可复算）

| 检查 | 门槛 | 实现 |
|---|---|---|
| 规格全部通过同一套 `_validate` | 无异常、面积 > 0 | 12 条全过 |
| 闭式 vs **独立算法**（矩形分解 + 平行轴） | 面积/惯性矩 rel ≤ 1e-12（角钢含形心 1e-9） | `_i_by_parts` / `_l_by_parts` |
| 闭式 vs **实测几何** | `K.section_props` 面积/ix rel ≤ 1e-9；`K.volume(beam)` = 面积 × 长度 rel ≤ 1e-9 | I16 / L63x6 / D76x4 |
| 系列单调 | 面积随规格严格递增 | 工字钢/角钢/圆管 |
| op 接线 | 消息与实体名都带规格名与标准号；未知规格报错 | `create.beam` |
