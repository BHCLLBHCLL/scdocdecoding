## 2. R58 工作项（P311–P314）

### P311 · 圆锥折弯 / 轴向折弯（最高优先，R57/P308 顺延）

- **动作**：圆锥折弯（母线为斜线的旋转面；展开长用中性层弧长闭式 `θ·(R_mid + Kt)` 的圆锥推广）；
  轴向折弯（沿圆筒轴向折边）；识别上与 `detect_bends`（圆柱）分开，避免"伪折弯/漏折弯"。
- **验收**：展开长闭式（手算对拍）+ 非法（锥角/半径退化）+ 极端 + 回放 + **既有圆柱折弯件展开不变**（纪律 60/67）。**成本**：1.5 天。

### P312 · 材料库与零件属性（元数据 + BOM 联动）

- **动作**：材料表（密度/弹性模量/牌号）+ 零件属性（材料/质量/表面积/自定义字段）；
  质量 = 体积×密度（闭式断言）；BOM 行带上材料与质量；.scdm 往返。
- **验收**：质量闭式（体积×密度，rel 1e-9）+ 属性往返 + BOM 联动 + 非法（未知材料/负密度）。**成本**：1 天。

### P313 · 可选补测（内存/帧率）｜P314 · 每轮维护（必做）

- P313 沿用 `tests/test_perf_budget.py` 口径；P314 快照/CI/口径同步 + 编号递增 + 轮次记录同轮补齐（纪律 65）。
