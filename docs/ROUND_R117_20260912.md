## 3. 边界（转 R118）

1. **指认只对「线性相关且 |cos| ≥ 0.99」**：低于阈值的冗余（多条共同作用）不指认来源，只标冗余。
2. **体检只定位、不修复**：双击能到现场，但把悬空引用改成数值/删掉仍要手工。
3. **体检行只能跳到草图与体**：配合 / 配置 / 命名选择的行目前只给状态文字。
4. **detach 只作用于「闭环消失」这一条路径**：其它同步失败仍按原样报告。
5. **A-3 尺寸驱动预览、A-4 拉前重解、A-5 锚点可控、A-7 三维模式选草图** 仍顺延；装配线仍在等 **B-1**。

## 4. 口径与纪律（R117 新增）

1. **诊断要指到「哪一条」**：冗余不满足于「有一条多余」，要给出被重复的那条序号；
   重复三次时指向**原始**那条，而不是它前面那条副本。
2. **体检要常驻**：状态栏一句话会滚掉，结构树节点每次重建都在（纪律 91：UI 承诺 = 实现并集）。
3. **破坏性动作要给选择**：删除体是默认，但要能选「保留（断开参数）」；两种结果都必须点名。
4. **Qt 对象必须有活着的 QApplication**（本轮踩坑）：测试里局部 QApplication 会被回收，
   完全没有 QApplication 时创建控件直接让进程崩（`STATUS_STACK_BUFFER_OVERRUN`，无输出）；
   统一用 `_ensure_app()` 把 app 挂在模块全局。
