## 2. R30 工作项（P175–P180）

### P175 · 特征族（孔/螺纹/成形）——广度第一优先

- **动作**：孔向导（直径/深度/攻丝标注）、螺纹示意、凸台/凹坑/百叶；命令 + 脚本 op + 特征历史。
- **验收**：闭式体积/包围盒断言 + 官方外形对照清单。**成本**：2–3 天。

### P176 · 梁/焊件首批

- **动作**：6 种梁轮廓 + 沿草图/边生成 + 焊接符号占位 + `.scdm` 数据模型。
- **验收**：轮廓参数化生成、体积与惯性矩闭式、源曲线变化后随动。**成本**：2–3 天。

### P177 · 图面尺寸第二批（多选/吸附/undo 接线）

- **动作**：多视图多尺寸选择与高亮、拖拽吸附、撤销栈接线（P48 仅单视图单尺寸）。
- **验收**：拖动可撤销/重做；吸附后偏移落在对齐值。**成本**：1.5–2 天。

### P178 · 可选补测（内存峰值 / 真实帧率，按 R29 的三条路线）｜P179 · 可选：`ref` 外部曲面库否证实验

### P180 · 每轮维护（必做）：快照/CI/口径同步；编号递增；关键功能完成即提交推送。
