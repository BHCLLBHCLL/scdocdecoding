# R55 轮次交付记录（2026-09-12）

> 规则：每完成一轮改进即重新基线并产出**下一编号**的规划。本轮（R55）执行 P299：**图纸标注——引线 + 形位公差框**。
> 交付：标注模型（`scdm/annotation.py`）+ SVG/DXF 标注层 + 画布拾取/拖动/吸附/undo + 对话框"加引线"入口。

## 1. 标注模型 `scdm/annotation.py`

| 项 | 实现 |
|---|---|
| 引线 `Leader` | 锚点 +（可选）折点 + 水平尾段；`points()` 给折线，`text_at()` 给文字位；`move_to()` 整体平移（折点随动）；空文字/负尾段报错 |
| 公差框 `GdtFrame` | 锚点=框左下角，`width×height`；11 种符号（position/flatness/…/runout）映射到字符（⌖ ⏥ ⏤ ○ ∥ ⊥ ∠ ◎ ⌯ ⌒ ↗）；`label()` = `⌖ Ø0.05 A B` |
| 非法 | 未知符号、公差值 ≤ 0、基准代号 > 3 字符、框尺寸非正、空引线文字、负尾段 |
| 往返 | `to_dict/from_dict` 全字段一致（含折点与基准） |

**关键差别（纪律 69 的正面用例）**：尺寸只有一个自由度（沿法向的标量偏移，R52 吸附的是偏移），
而标注锚点是**自由二维点**，因此吸附直接用 `SnapIndex.snap(点)` —— 自由度决定吸附量。

## 2. 导出（`scdm/drawing.py`）

`svg_sheet(..., annotations=)` 与 `write_dxf(..., annotations=)` 新增标注层：
引线走 `NOTE` 层（SVG class="note"，蓝色）、公差框走 `GDT` 层（绿色），文字随层输出。
标注**不入几何**：本轮断言同时检查"导出含标注"与"模型体积/面数不变"。

## 3. 画布与对话框（`scdm/gui/sheet.py`）

- `SheetCanvas(..., annotations=)`：拾取（`pick_annotation`）、拖动（`drag_annotation`，**二维吸附**）、
  绘制（引线折线/公差框 + 文字，热态高亮）；
- **undo 快照升级**：`state() = {offsets, notes}`（此前只有偏移列表），`set_state()` 同时兼容旧的裸列表；
  三种拖动（尺寸/多选/标注）共用一步一快照；
- `SheetDialog`：新增"加引线"按钮与 `add_leader(text)`（锚点取第一个真实吸附靶点）、
  导出带上 `canvas.notes`、提示文案更新。
