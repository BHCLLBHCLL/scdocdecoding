## 2. R50 工作项（P277–P282）

### P277 · 敲落 `knockout`（最高优先）

- **动作**：`K.knockout(solid, face, diameter, web, web_count)` —— 环切（`prism` 造环 + `cut`）后按 `web_count` 用 `fuse` 补回桥接片；
  判据：**切除面积占比**（闭式）+ **单连通**（`K.explore(solid,'shell')` 数量/壳数不变）；非法 `web ≥ 直径`；单筋极端；**展开兼容**（纪律 60）。
- **验收**：闭式 + 单连通 + 非法 + 极端 + 展开 五条断言。**成本**：1 天。
