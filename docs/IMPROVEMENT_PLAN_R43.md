## 2. R43 工作项（P241–P246）

### P241 · 百叶 `louver`（最高优先）

- **动作**：按 `bead_groove` 的形状实现 `louver(solid, face, length, width, height, origin=None)`；
  闭式判据用“开口面积 × 板厚”（唇边抬起为加料，单列），非法参数（长/宽/高 ≤ 0 或超出面）拒绝。
- **验收**：闭式 + 非法 + 极端（极小百叶）+ **展开仍成功**（`unfold`/`flat_pattern` 不抛）。**成本**：1 天。

### P242 · 敲落 `knockout`

- **动作**：带细筋的环切（圆形/矩形），参数 `diameter`、`web`、`web_count`；判据用“切除面积占比”+ 保留筋的连通性（实体仍单连通）。
- **验收**：闭式 + 非法（web ≥ 直径）+ 极端（单筋）+ 展开仍成功。**成本**：1 天。

### P243 · 梁/焊件首批｜P244 · 图面尺寸第二批｜P245 · 可选补测（内存/帧率）

### P246 · 每轮维护（必做）：快照/CI/口径同步；编号递增；关键功能完成即提交推送。
