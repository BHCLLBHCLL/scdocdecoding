## 3. 边界（本轮明确不做的部分，入册 R103 候选）

1. **刚体变换后不保持重放不变量**：`tool.move` / `op_move` 只平移当前形状，不随动 `base_shape`，
   因此"先移动再改特征参数"会被拒绝（理由是包围盒/体积不一致）。按纪律不静默重放：
   留作 R103「刚体变换 base 随动」。
2. **布尔/导入之后的实体**：文档级 `record_doc_feature` 覆盖整档重放，但**单体**特征栈与当前形状
   不再一致 → 同样明确拒绝（本轮测试锁定该行为）。
3. **脚本层只补了 5 类特征记录**（孔族/抽壳/倒圆/倒角/拉动）：其余成形类脚本 op 仍未记录，
   列表见 R103 候选。
4. **撤销快照的额外成本**：带特征历史实体的快照现在多存一份基准 BREP（无特征的导入件不受影响，
   因为 @@bases@@ 只收有历史的实体）；50 步上限内量级可接受，大装配场景在 R103 复测。
5. **GUI 对话框本身只由冒烟测试覆盖**：解析与应用逻辑在库层单测（`parse_edit_lines` / `apply_edits`），
   对话框交互（Qt 事件）仍按台账声明豁免。
