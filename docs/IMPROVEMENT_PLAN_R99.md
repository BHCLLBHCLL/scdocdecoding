## 2. R99 工作项：P440 装配爆炸动画帧

- **动作**：在 `scdm/assembly.py` 现有三模式位移之上加**帧序列**：`explode_frames(offsets, frames)` 返回每帧的位移
  （线性插值 `offset * t`，`t = i/(frames-1)`），并让 GUI 能按帧推进（一次前进/后退一帧，末帧等于完整爆炸）。
- **验收**：帧位移可数（每帧 = 位移 × t，闭式对拍 1e-12）；`t=0` 帧等于原位、`t=1` 帧等于完整爆炸；
  帧序列可回放（op 接受 `frame`）。**成本**：0.5–1 天。
