## 1. 吸附引擎 `scdm/snaptools.py`

| 项 | 实现 |
|---|---|
| 靶点 | 视图折线的**端点 / 中点**、段与段的**交点**（Cramer 2×2 精确解，只计两段内部）、可选**网格** |
| 判据 | 距离 ≤ tol 取最近；同距按 **端点 > 交点 > 中点** 优先级（端点是对几何最具体的陈述） |
| 网格 | `grid > 0` 时无条件吸到最近网格节点（`round(p/g)*g`，精确倍数——网格的意义即在此） |
| 重建 | `rebuild(views)`：**被删除的边不再吸引手柄**（本轮非法用例） |
| 规模护栏 | 仅当段数 ≤ 64 时收集交点（图纸视图是几十段；网格化模型不参与） |

## 2. 画布 `scdm/gui/sheet.py`

- **多选**：Ctrl 点击追加/取消；空白处拖动 = 框选（橡皮筋；Ctrl 追加）；
- **成组移动**：拖动任意手柄，整个选择集按**同一位移向量**移动，相对间距不变；
- **吸附量是“尺寸线”而非“自由点”**：`Dimension.offset` 是沿法向的标量，所以吸附解算的是
  **过靶点的偏移** `offset = (p − a)·n`（闭式）；R52 第一版写成“把点吸到靶点”，
  测试当场抓出：横向量被投影吃掉，手柄根本到不了靶点（尺寸线只能垂直自身滑动）；
- **undo / redo**：`scdm.history.History` 存**偏移快照**（浮点列表，逐位精确）；
  一次拖动 = 一步（首次移动压入前态，`end_drag` 压入结果态）；Ctrl+Z / Ctrl+Y + 对话框按钮；
- **另修**：隐藏部件 `resize()` 不触发 resizeEvent → 画布在 `to_px/to_view` 前按当前尺寸自校验并重拟合
  （本轮测试暴露：手柄算到画布外，框选漏选）。
