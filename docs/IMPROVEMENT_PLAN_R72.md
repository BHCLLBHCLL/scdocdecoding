## 2. R72 工作项（P358–P361）

### P358 · 导入保真：ref 族差异表（最高优先）

- **动作**：对 ref 族样例做**逐项计数**差异定位（体/面/边/顶点数、曲面类型分布、容差、退化面、自由边），
  产出 `docs/REF_FAMILY_DIFF.md`（表 + 复算命令）；能修的一项当场修并给测试，不能修的写明**为何不能修**。
- **验收**：差异表每项可数 + 至少一项有处置结论（修复或明确不修的理由）+ 复算命令可跑。**成本**：1–1.5 天。

### P359 · 图面尺寸链第三批

- **动作**：极值/统计两种叠加**并列标注**（同一链两条总尺寸，文字分别带 ±worst / ±rss）+ 链线图形化（注记层）。
- **验收**：两条标注都在 SVG/DXF + 链线为注记（不入几何、不入包围盒）+ undo 往返。**成本**：0.5–1 天。
