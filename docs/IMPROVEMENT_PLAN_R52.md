## 2. R52 工作项（P287–P290）

### P287 · 图面尺寸第二批（最高优先，R50/R51 顺延两次）

- **动作**：尺寸多选（框选 + Ctrl 追加）、拖动吸附（端点/中点/交点/网格）、undo/redo 入 `scdm.history`。
- **验收**：吸附命中坐标闭式（1e-9）+ 三条 undo/redo 往返一致 + 非法（吸附到被删除的边）；**成本**：1 天。

### P288 · 梁第二层：沿折线 + 焊件组元

- **动作**：`beam_polyline(profile, points)` 沿折线分段生成并按段长闭合式复算；焊件组元（父梁 + 子梁共享截面/材料）；
  焊接符号**元数据模型**（`.scdm` 承载，暂不建几何），面板占位升级为 live 或明确保留占位（写明理由）。
- **验收**：折线梁体积 = Σ A×段长（1e-9）；组元增删后子梁随动；符号元数据往返一致。**成本**：1.5 天。

### P289 · 可选补测（内存/帧率）

- **动作**：沿用 `tests/test_perf_budget.py` 口径补一次内存峰值与帧率基线。**成本**：0.5 天（可选）。

### P290 · 每轮维护（必做）

- 快照/CI/口径同步（`tools/gen_devplan_snapshot.py --update`）；编号递增；轮次记录与规划同轮补齐（纪律 65）。
