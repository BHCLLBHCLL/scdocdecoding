## 2. R63 工作项（P331–P334）

### P331 · 装配配置第二批：配置驱动属性 + BOM（最高优先）

- **动作**：配置里保存**零件属性快照**（材料/自定义字段）与**数量**；切换配置 → 属性与 BOM 随动；
  `.scdm` 往返（清单版本 +1）；左栏/状态栏提示当前配置。
- **验收**：配置切换后 BOM 行可数变化（材料名/质量按密度比/数量）+ 快照往返一致 + 非法（未知配置/引用已删除实体）。**成本**：1 天。

### P332 · 贴体体网格首批

- **动作**：边界格按实体面裁剪（`K.common` 体素盒 ∩ 实体 → 再四面体化或按裁剪体积计），
  使体积误差随格距**二阶**收敛；沿用 P327 的闭式对拍与门槛清单。
- **验收**：同一球体在相同格距下误差比体素版低一个量级（可数）+ 退化 0 + 回放一致 + 非法（空裁剪）。**成本**：1.5 天。

### P333 · 可选补测（内存/帧率）｜P334 · 每轮维护（必做）

- P333 沿用 `tests/test_perf_budget.py` 口径；P334 快照/CI/口径同步 + 编号递增 + 轮次记录同轮补齐（纪律 65）。
