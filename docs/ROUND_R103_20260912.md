## 2. 关键实测

| 项 | 实测 |
| --- | --- |
| 平移 (10,0,0) | 包围盒逐轴偏移 **+0.01 m**（±1e-12）；`can_replay` 真；改 ⌀5→⌀8 → V = **3.49734517543e-06**（闭式） |
| 旋转 90°（+Z，过原点） | 包围盒 = 解析映射 `(x,y)→(−y,x)`（±1e-12）；体积不变；参数仍可改 |
| 镜像（x=0） | x 区间翻转到 `[−0.02, 0]`，体积不变 |
| 撤销 | `restore` 后 `base_pose == []`、包围盒回原位、`can_replay` 仍为真 |
| 工程往返 | 清单含 `base_pose: [["translate", …]]`；重载后继续改 ⌀8→⌀4 成功 |
| 工具/脚本路径 | `get_tool("tool.move")` 与 `OPS["tool.move"]` 两条都保持不变量 |
| A-2 八个成形 op | 每个：`stack.ops() == [op]`、`can_replay` 真、改参数后**体积与面数 == 原生重建**（rel 1e-6） |
| A-3 对话框 | 文本构建 → 解析 → 应用：⌀5→⌀8 落闭式；坏表达式/坏行**零变更**（体积与参数都不动） |
| A-4 特征树 | 参数行负载 `("feature_param","B1",0,"diameter")` / `(…,"depth")`；打断历史后**无参数行**且 tooltip 含"不可重放…不一致" |
| 树重建成本（纪律 85） | 带 3 个特征的实体：`populate_tree` **34.74 ms → 1.52 ms**/次（无特征基线 0.20 ms）；`can_replay` 自身 **34.55 ms → 0.02 ms**/次（命中缓存）。做法：`FeatureStack.cached_verdict()` 以「形状对象身份 + 参数签名 + scale」为键，参数或形状一变即重算（调用计数测试锁定） |

## 3. 边界（转 R104 候选，均已入册）

1. **配合/对齐路径**：`asm.mate` 的 face-flush / axis-align 与 `K.align_faces` / `K.align_axes`
   不是具名刚体 op，位姿无法回放 → 该路径仍会被 `can_replay` 拒绝（未静默）。
2. **UI 无刚体旋转入口**：`rotate_body` 目前只有 API/脚本可达，移动工具有平移无旋转。
3. **脚本层不记文档级特征**：`op_combine` / `op_split` / `op_mirror` 不写 `record_doc_feature`
   （GUI 会写），因此脚本产出的布尔结果没有整档重放链。
4. **端到端 handler**：`det.params` 对话框与树双击的 `exec_` 循环仍只由冒烟测试覆盖；
   本轮覆盖的是对话框控件往返与全部副作用逻辑。
