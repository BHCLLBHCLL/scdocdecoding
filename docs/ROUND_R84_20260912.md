## 2. 采用：缝合容差 1e-5（0.01 mm）

R72 曾否证"提高缝合容差"（当时 1e-3 都关不上 SampleModel1 的 84 个自由环，还会改实体划分）。
R73–R83 之后几何已经精确，本轮**重测**同一问题（1e-6 vs 1e-5，全库六样例）：

| 样例 | 缺口 | 自由环 | 缝边 | 面数 | 耗时 |
|---|---|---|---|---|---|
| SampleModel1 | 0 → 0 | 0 → 0 | 0 | 109 | 1.45 s |
| SampleModel4 | **375 → 347** | **86 → 76** | 18 → 16 | 149 | 1.59 s |
| samplemodel2 | **1272 → 1242** | 359 → 356 | 34 → 33 | 1813 | 6.81 s |
| samplemodel3 / 5 | 0 | 0 | 0 | 111 / 1288 | 0.09 / 2.43 s |
| samplemodel6 | 3 | 2 | 0 | 28 | 0.10 s |

面数**一个都没少**（没有把面缝掉），耗时无回退。实现：`scdm/import_sab.py` 新增 `_SEW_TOL = 1e-5`（导入路径显式传入），
内核默认仍是 1e-6，供其他调用方使用。
