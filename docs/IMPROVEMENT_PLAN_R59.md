## 2. R59 工作项（P315–P318）

### P315 · U 型槽折弯识别 + unfold 支持（最高优先，R58 遗留缺口）

- **动作**：把**构造夹持面**从折弯配对里剔除——判据：相邻平面的法线**平行**（同向或反向）且平面间距离 ≈ 0（构造夹持面成对出现、法线共线）；
  或者由 `axial_bend` 显式标记夹持面（返回几何+标记），检测器优先用标记。
- **验收**：U 型槽 `detect_bends` 返回 2 条 90° 折弯（r 正确）+ `unfold` 展开长 = `w + 2(立边 + BA)`（手算对拍 rel 1e-9）
  + **既有 L 折弯/多弯链/卷边测试全部不变**。**成本**：1 天。

### P316 · 材料库与零件属性（元数据 + BOM 联动）

- **动作**：材料表（密度/弹性模量/牌号）+ 零件属性（材料/质量/表面积/自定义字段）；质量 = 体积×密度；BOM 行带材料与质量；.scdm 往返。
- **验收**：质量闭式（rel 1e-9）+ 属性往返 + BOM 联动 + 非法（未知材料/负密度）。**成本**：1 天。

### P317 · 可选补测（内存/帧率）｜P318 · 每轮维护（必做）

- P317 沿用 `tests/test_perf_budget.py` 口径；P318 快照/CI/口径同步 + 编号递增 + 轮次记录同轮补齐（纪律 65）。
