## 3. 边界（转 R112）

1. **到面只认平行面**：与草图不平行的面直接拒；斜面的「到面」（沿法向投影 / 最近点 / 到实体表面）未做。
2. **拉伸手感 = 按草图所画**：`extrude_active` 不先重解表达式尺寸。若脚本只写了表达式尺寸而没走
   `set_dimension` / `redrive_expressions`，拉出来的是**图上几何**（本轮用一条测试钉住这条口径；
   R112 若要改成「拉之前先重解」，属于改语义，需要单独评估会动的几何）。
3. **`dimN` 只覆盖本草图**：不支持跨草图引用（如 `草图B#3`），也不支持引用求解结果之外的量。
4. **DOF 只在草图模式显示**：三维模式不显示装配整体自由度；过约束只在 `dof_report` 里报数，UI 未指出**哪一条**冲突。
5. **A-3 草图镜像/阵列、A-4 按捕捉半径焊接、A-5 尺寸驱动预览**仍顺延（R111 计划 A 组的剩余项）。
6. 装配线仍在等 **B-1 装配层级 / 局部坐标系**。

## 4. 口径与纪律（R111 新增）

1. **`dimN` 绑定约束序号**，且只有 `dist`/`radius` 行有值；拒绝信息必须点名是「越界」还是「不是尺寸」，
   并列出**可引用的序号**——否则用户拿不到修复所需的映射。
2. **链上任何位置的循环都算循环**：解析时把「因循环而缺席的名字」报成循环（不是「未知参数」），
   并且在**下发求解之前**拦下，保证拒绝是原子的。
3. **无法解析的尺寸行不得从树里消失**：序号是唯一的修复入口（纪律 91：UI 承诺 = 实现并集）。
4. **测量只读**（纪律 85）：`dof_report` 在副本上求解，测试断言点坐标与体积不变。
5. **多闭环草图 = 一环一体**（R107 口径）：多闭环的体积断言必须**求和**，不能只量 `bodies[0]`
   （本轮探针踩过一次：三闭环只量到第一个体，把 430 读成 150）。
