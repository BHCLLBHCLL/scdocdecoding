## 2. R28 工作项（P163–P168）

### P163 · 大模型 GUI 可用性实测（最高优先，积压十五轮）

- **动作**：用 samplemodel2（37 体/1810 面）与 samplemodel5（80 体/1288 面）实测“导入 → 视口构建 → 首帧”三段耗时与内存峰值；
  若视口构建占比高，按体/视锥懒装配（先只装配可见体，平移/缩放时补齐）。
- **验收**：打开到可交互 **< 20 s**（含导入）；给出帧率基线（静止 + 旋转各一次测量）；数据写入轮次文档。
- **成本**：1–1.5 天。

### P164 · 特征族与梁焊件（广度）

- **动作**：孔向导（直径/深度/攻丝标注）、螺纹示意、凸台/凹坑；6 种梁轮廓 + 沿草图/边生成。
- **验收**：闭式体积/包围盒断言 + 官方外形对照。**成本**：4–6 天（可分两轮）。

### P165 · 图面尺寸第二批（多选/吸附/undo 接线）

- **动作**：多视图/多尺寸选择与高亮、拖拽吸附、撤销栈接线（P48 只做了单视图单尺寸拖拽）。
- **验收**：拖动可撤销/重做；吸附后偏移落在对齐值。**成本**：1.5–2 天。
