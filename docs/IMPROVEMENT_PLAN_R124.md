## E. 口径（R124 起沿用）

1. **数字要能看见**（R123）：锚点这类参数要在界面上画出来。
2. **标记与状态条同源**（R123）：只标用户选定的值，默认值不标。
3. **陈旧标记要清**（R123）：标记属于上一次操作，选择一变就清。
4. **文档图要能重生成**（R123）：参考图连同生成命令入库。
5. **退化消息要修**（R123）：把「循环」说成「笔误」就改掉。
6. **界面要追上库层 / 默认值就是历史行为 / GL 内容要单独取 / 工具要能离屏自检**（R122）。
7. **挑选要有两个方向 / 目标从界面里点 / 锚点显式化 / 前提错了要更正**（R121）。
8. **批量操作要能挑 / 只读就是只读 / 动作与目标都可按范围给 / 两条路径合一**（R120）。
9. **修复要保留意图 / 破坏性动作先说后做 / 作用域收到具体条目**（R119）。
10. **诊断的下一步是修复 / 删除按值不按下标 / 冻结 = 把当前几何写成数**（R118）。
11. **诊断指到「哪一条」/ 体检常驻结构树 / 破坏性动作给选择 / Qt 对象必须有活着的 QApplication**（R117）。
12. **标记能说话 / 体检覆盖所有按 ID 指向的结构 / 选择顺序是用户意图 / 不连续就拒绝**（R116）；
    **诊断落在几何上 / 一行坏数据不许让整张报告失效 / 模式的真相在会话 / 文件类型看内容**（R115）；
    **画出来的和能选中的是同一份几何 / 拾取偏好可预期**（R114）。
13. **一个概念一个数 / 局部化与计数同源 / 测量只读 / 多闭环体积断言求和 /
    再拉一次不复制已建体 / 尺寸单位三分**（R107–R112）。
14. 每轮结束照旧：定向 + 定向回归批 + 全量回归 + 快照 `--check`（两种解释器）+ 同轮文档 + 提交推送。
