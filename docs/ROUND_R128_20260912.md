## 3. 边界（转 R129）

1. **体积口径 68 例**：面/边都对、体积不是 SpaceClaim 的值（孔、切、布尔之后）——最大的单类，未查因。
2. **多体 28 例**：一个文档多个体时我们只读到 1 个（镜像/阵列/装配/多体分割）。
3. **边重复计数 12 例**：倍数都是 2×，怀疑把 coedge 当 edge 数。
4. **2 例 facet 网格格式**读不出：`15_mesh_stl_import_001`（edge table 计数越界）、`20_combo_mesh_032`（body terminator）。
5. **点大小只挂在草图页**；A-6（三维模式选草图曲线）、A-7（交互式预览清单）、A-19（预览跨模式）顺延；装配线仍等 **B-1**。

## 4. 口径与纪律（R128 新增）

1. **官方语料是尺子，不是我们的测试**：`scdm_cases` 里的文档由 SpaceClaim 写、由 SpaceClaim 读回；我们只读、只对照，绝不写进去。
2. **读不出的要分类计数**：解析失败不是「跳过」，是一类结果（本轮把 55 例异常压到 2 例并逐类记名）。
3. **崩溃要变成报告里的一个数字**：三处缺陷都先变成 check 文案/计数字段，再谈修不修得动。
4. **一个设置要立刻看得见、也要活过重启**：点大小既 `option_changed` 立即重画，又写 `QSettings`。
5. **测试动过的全局状态要放回去**：本轮全量首跑 1010 passed / 1 failed，就是 R127 的用例改了持久化设置没还原——同轮补上清理。
