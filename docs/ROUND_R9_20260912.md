## 交付：环面窗口改用**采样 bbox** 判定（限定在 torus）

**背景（R8 测得）**：窗口接受用的是“建面 bbox 与记录 bbox 的距离”，而 `Bnd_Box` 对**周期曲面的裁剪片膨胀约 4%**，
超过 2% 阈值 → 正确窗口被拒 → 退回布尔裁剪 → 一个面被切成多片（samplemodel2 多出 48 个面）。

**R9 做法（已落地）**：`_face_from_window(..., accurate=...)`——torus 面用**面 UV 采样 bbox** 计算距离并据此接受窗口，
其余曲面（spline/sphere/cone）保持廉价路径。四轮尝试踩出的边界条件全部写进代码注释：

| 变量 | 实测 | 定值 |
|---|---|---|
| 采样网格 | 7 点会漏掉整圈片的 90° 极值（bbox 偏小 → 正确窗口反被拒）；13 点修好 sm2 但扰动 SampleModel4 11 个面 | **7**（各样例都取到最优） |
| 适用范围 | 全曲面采样 → 导入 8.4→16.1 s；仅 torus → 约 7.2 s | **仅 torus** |
| 接受准则 | 放松到“容差+覆盖”会放进错窗口（SM4 丢 11 面） | **仍是 2% 距离**，只换 bbox 来源 |
