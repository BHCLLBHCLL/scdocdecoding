## 2. 关键实测

| 项 | 实测 |
| --- | --- |
| 7 类运动副 | 每类 `dof == mates.DOFS[type]`、`removes == 6 − DOF`；矩阵满足该类条件（刚性/旋转/圆柱/螺旋：B 帧原点→A 帧原点且轴向一致；平面：法向相反；球：仅原点；距离：原点沿 A 轴偏移 value）；目标体**不动**，移动体确实移动 |
| 过约束 | 刚性后再加旋转 → 拒绝，理由含「过约束：体对 … 已固定 6 个自由度，再加 revolute（5 个）超过 6」；`mates` 列表不增长、体不动 |
| 对齐 | `align_faces`/`align_axes` 重构后与旧实现**逐位一致**（cog / bbox / volume diff 均为 **0.000e+00**，独立探针） |
| A-1 不变量 | 对齐/配合之后 `can_replay` 仍为真；改 ⌀5→⌀8 / ⌀9 / ⌀7 全部落在闭式（rel 1e-6）；对齐结果与内核 `align_faces` 单独作用**逐位一致**（cog/bbox ±1e-12） |
| 位姿顺序（本轮最硬的一个坑） | 修复前：配合旋转后重放把孔的 selector 送到别的面 → 体积 **3.6073e-06** vs 闭式 **3.8037e-06**；改为「base → 特征（自带位姿）→ 尾部位姿」后回到闭式 |
| 撤销 | `restore` 后 `mates == []`、`base_pose == []`、几何回原位 |
| 工程往返 | `mates` 列表与位姿矩阵落盘，重载后 `can_replay` 真、可继续改 ⌀7 到闭式 |
| 脚本链 | `insert.box×2 → create.hole → asm.mate（rigid / faces）→ det.params` 全部可回放 |
| **未记录的移动必须被发现** | 量/面数都是平移不变量，只查这两项时「未记录的平移」会被误判为一致，下一次改参数会把实体**静默挪回原位**。本轮给 `replay_mismatch` 补上**包围盒**判据（1 nm + 1 ppm 相对容差）；未记录平移现在报「包围盒不一致」并拒绝编辑，几何一动不动（新增测试） |

## 3. 边界（转 R105 候选）

1. **无装配层级**：配合是把 B 一次性摆到 A 的**当前**帧；之后改 A 不会带动 B（无父子链/局部坐标系）。
2. **过约束判据保守**：按 `DOFS` 表计数，两条旋转副（物理上常见）也会被拒——是有意的「拒绝而非猜测」。
3. **驱动量只在求解那一刻生效**：没有运动学动画/多帧求解（R99 的爆炸帧是另一条路径）。
4. **配合与组件移动不联动**：`asm.move` 平移组件后不会重新求解已有配合。
5. **爆炸图仍走未记录平移**：`asm.explode` 用 `K.translate` 直接改形状（R88/R99 的位移数学刻意不依赖内核），
   因此爆炸后带特征历史的实体会被判「包围盒不一致」而拒绝编辑（**不再静默挪回**，但也不可编辑）。
   修法是把 explode 的平移回调改成 `KernelDoc.translate_body`（连同 3 处调用点/测试），列入 R105 A-6。
