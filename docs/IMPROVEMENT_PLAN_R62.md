## 2. R62 工作项（P327–P330）

### P327 · 网格质量门槛 + 体网格首批（最高优先）

- **动作**：质量门槛（`aspect_max / min_angle_min / jacobian_min / 最大退化数`）作为**可判定验收**：
  超限时返回**清单**（哪个三角形、哪个指标、超多少）而不是布尔；体网格首批用"四面体填充 + 体积和 vs 实体体积"闭式对拍。
- **验收**：门槛判定与手算一致 + 超限清单可数（索引/指标/超差量）+ 体积和与 `K.volume` 一致（rel 1e-6，离散误差显式）+ 非法（空网格/全退化）。**成本**：1.5 天。

### P328 · 装配配置第二批（配置驱动 + BOM 联动）

- **动作**：配置驱动可见性/抑制（已有）扩展到**零件属性快照**（同零件不同配置不同材料/数量）+ BOM 行按配置出表 + 视图状态往返。
- **验收**：配置切换后 BOM 行变化（可数）+ 属性快照往返 + 非法（未知配置）。**成本**：1 天。

### P329 · 可选补测（内存/帧率）｜P330 · 每轮维护（必做）

- P329 沿用 `tests/test_perf_budget.py` 口径；P330 快照/CI/口径同步 + 编号递增 + 轮次记录同轮补齐（纪律 65）。
