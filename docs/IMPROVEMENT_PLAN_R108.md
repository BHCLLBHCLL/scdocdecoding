## E. 口径（R108 起沿用）

1. **轮廓规范化**：一个闭环在特征里只以 `("circle", c, r)` 或 `("poly", [pts])` 存储（矩形折成 4 点 poly），
   因此"一个特征 = 一个闭环"，多轮廓就是多体多特征。
2. **驱动尺寸必须验证驱动量本身**：求解器残差小 ≠ 目标尺寸对；`set_dimension` 直接量取被驱动的距离/半径并比对目标，
   失败则约束与曲线一起回滚。
3. **求解失败的连锁**：闭环消失/求解不收敛都走"报告 + 回滚"，绝不重建一个错的实体。
4. 每轮结束照旧：定向 + 全量回归 + 快照 `--check`（两种解释器）+ 同轮文档 + 提交推送。
