# R86 轮次交付记录（2026-09-12）

> 规则：每完成一轮改进即重新基线并产出**下一编号**的规划。本轮（R86）执行 P411：**锥面片能否像球面一样真实裁剪**。
> 结论是**不能**，而且理由比"慢"严重得多：**锥面裁剪会让进程在 OpenCASCADE 内原生崩溃**。
> 交付：把这次崩溃变成一条**可复现的守卫**（+ 回归测试），并把环面/锥面的拒绝理由量化归档。

## 2. 崩溃的可复现最小事实

samplemodel2 的**锥面记录**（半角 **−30°**、半径 **0.246214**）：
曲面构造成功（`Geom_ConicalSurface` 不报错），随后 `_trimmed_face` 内部让解释器**直接退出**（无 Python 异常、无栈）——
这是原生崩溃，`try/except` 拦不住，唯一的办法是**根本不调用**。
本轮的探针第一次跑就死在这里：7 个面正常（含 −30°/0.274 那个）、第 9 个（面 270）进程消失。

## 3. 修：守卫 `_trim_surface_allowed()`

`_trimmed_face` 的第一行改为曲面类型闸门：只允许 **柱面** 与 **球面**（`GeomAbs_Cylinder` / `GeomAbs_Sphere`），
其余（锥/环/平面/样条）一律返回 `None`。效果（同一进程内复现）：

| 调用 | 之前 | 现在 |
|---|---|---|
| 崩溃那个锥面 | 进程退出 | `None`，0.142 s |
| 环面 | 0.54 s 后可能成功 | `None`，0.000 s |
| 柱面 / 球面 | 正常 | 正常（不变） |

导入结果**完全不变**（守卫只拦住了本来就没启用的路径）：合计缺口 1352、自由环 290，六样例与 R85 一致。
