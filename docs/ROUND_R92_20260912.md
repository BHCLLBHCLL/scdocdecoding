> 规则：每完成一轮改进即重新基线并产出**下一编号**的规划。本轮（R92）执行 P426：**槽钢（C 形）截面**。
> 交付：`scdm/beams.py` 新增第 7 种截面 `c`（腹板贴左的 C 形）+ 闭式截面特性 + 3 条标准规格；
> 这是模块里**第一个非对称轧制截面**（形心不在腹板中心线上），验收因此比 I 形多一条：**几何与闭式必须用同一套坐标约定**。

## 1. 截面定义与闭式

`c` 参数：`h, b, tw, tf`（高、翼缘宽、腹板厚、翼缘厚），腹板贴 **x=0**，上下翼缘向右伸出：

```
A  = tw·h + 2·(b−tw)·tf
cx = [tw·h·(tw/2) + 2·(b−tw)·tf·((b+tw)/2)] / A      ← 不在 b/2 上
cy = h/2                                             （上下对称）
ix = tw·h³/12 + A_web·(h/2−cy)² + 2·[(b−tw)·tf³/12 + A_f·(y_f−cy)²]
iy = h·tw³/12 + A_web·(tw/2−cx)² + 2·[tf·(b−tw)³/12 + A_f·((b+tw)/2−cx)²]
```

标准规格（GB/T 706 公称尺寸）：`[10` 100×48×5.3×8.5、`[12.6` 126×53×5.5×9.0、`[16` 160×63×6.5×10.0。
口径同 R87：只登记公称尺寸，本模块不建圆角，所以与手册"含圆角"值差约 1%（[10：我们 1255.9 mm²、手册 1274 mm²）。
