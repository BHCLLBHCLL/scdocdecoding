# R99 轮次交付记录（2026-09-12）

> 规则：每完成一轮改进即重新基线并产出**下一编号**的规划。本轮（R99）执行 P440：**装配爆炸动画帧**。
> 交付：爆炸位移之上加**闭式帧插值**（`frame_offsets` / `explode_frames`），op 接受 `frames/frame` 并按帧应用；
> "动画"因此**不存任何中间状态**，每帧都像终态一样可复算、可回放、可断言。

## 1. 帧公式（可复算）

```
t          = frame / (frames - 1)          # frame 0 = 原位, frames-1 = 完整爆炸
offset(cid) = final_offset(cid) * t        # 方向不变，模长线性
```

非法请求**报错**：帧数 < 2、帧号越界（不静默给零位移）。
op 上：`asm.explode` 的 `frames`（≥2 时启用）与 `frame`（默认末帧）；消息里带 `帧 i/(n-1)`。

## 2. 验收（每条都可复算）
