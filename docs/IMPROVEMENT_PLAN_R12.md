## 2. R12 工作项（P69–P74）

### P69 · 用**廉价预筛**接回记录窗口（最高优先）· 🟡 R11 续做时的新发现

- **动作**：O(1) 预筛后再做采样验证：①圆柱——仅当**解析弧跨度 > π**（切分判据）时试记录 uv 窗口；
  ②环面——仅当“记录窗口跨度 < 解析/2”或当前面会被切成多片时试；验证仍用采样 bbox，但只跑命中的少数面。
- **验收**：samplemodel2 **1813 ± 0**、漂移 0.0%、导入 ≤ 10 s。
- **成本**：1 天。
- **R11 续做新发现（先解决它，否则预筛也白搭）**：对 5 个四分之一片环面逐候选量测后发现，**记录的 uv 四连并不能直接当“面窗口”用**——
  按 `(u0,u1,v0,v1)` 建面得到的片比记录 bbox **大 12%–280%**（例：模型 14 面 1547 建出 y 超 0.67，而记录 y 跨度只有 0.24）。
  由几何反推，该面的正确读法更像 `(v0,v1,u0,u1)`：u 跨度 0.526 rad、环半径 0.7374 ⇒ 弦长 0.387，正好等于记录 z 跨度 0.39。
  **P69 第一步**：对 1547/2078/2120/2209/539 逐候选完整量测（含 `(v0,v1,u0,u1)` 与符号组合），先**定死四连的语义**，再做预筛。

### P70 · 无 uv 记录的环面（面 1697）

- **动作**：改用**边界曲线定窗口**（椭圆/直线边的参数区间或端点投影），这是 R9 就定下的方向，现只剩 1 个面做样本。
- **成本**：0.5–1 天。

### P71 · SampleModel4 的 35 个未重建面（`ref` 引用表）

- **动作**：定位 ACIS `ref N` 引用表/延迟几何节（R8 四条排除证据 + SAT 极点交叉定位）。
- **验收**：SampleModel4 177/177；`--strict` 退出 0。
- **成本**：2–3 天（高风险）。

### P72 · 官方层级参与交互（积压四轮）

- **动作**：只读显示模型（part/component/layer → 显示分组）+ 勾选显隐/隔离。
- **验收**：勾选即时生效、几何不变。
- **成本**：2 天。

### P73 · 大模型 GUI 可用性（积压四轮）

- **动作**：导入 → 视口构建 → 首次渲染耗时/内存实测，必要时懒装配。
- **验收**：< 20 s 可交互 + 帧率基线。
- **成本**：1–1.5 天。

### P74 · 每轮维护（必做）

- **动作**：快照/CI/口径同步；编号递增。
- **成本**：0.5 天/轮。
