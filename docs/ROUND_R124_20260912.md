## 4. 口径与纪律（R124 新增）

1. **画不出来就不算标记**：`在渲染器里` ≠ `在屏幕上`；点要有 cell 才成为图元，否则代码在说谎。
2. **校验不依赖平台**：参考图比场景/模式条/体检数，不比像素——离屏与原生渲染本来就不一样。
3. **一个数只能有一个来源**：回归批的组成落盘成一个文件，此后每轮只追加（纪律 84）。
4. **谁说的算**：尺寸写的是什么，拉出来就得是什么；改口径时同轮更新锁口径的测试（R111/R113 两条）。
5. **顺带发现的缺陷要落测试**：点标记不渲染、跨草图口径，两处都补了断言（纪律 91）。
