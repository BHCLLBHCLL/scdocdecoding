## 2. R49 工作项（P271–P276）

### P271 · 百叶 8 层接线（最高优先）

- **动作**：脚本 op `create.louver`（`target/face_i/length/width/height`）→ `Feature(op="louver")` 标签与派发 → 目录 `C("create.louver", …)` + live → `_do_create_louver` → 回放等价断言（纪律 54：最小步骤）→ 视口开口标记（纪律 56 双护栏）。
- **验收**：闭式（含唇边）+ 非法 + 极端 + 回放 + 视口 五项齐备，与凹坑/攻丝孔同标准。**成本**：1 天。

### P272 · 敲落 `knockout`

- **动作**：带筋环切（圆/矩），参数 `diameter`、`web`、`web_count`；判据“切除面积占比”+ **单连通**；非法（`web ≥ 直径`）；单筋极端；**展开兼容**（纪律 60）。**成本**：1 天。
