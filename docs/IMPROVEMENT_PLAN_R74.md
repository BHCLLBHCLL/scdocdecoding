## 2. R74 工作项（P367–P370）

### P367 · 真实边界裁剪正式化（最高优先，直指 129/2546 条自由边）

- **动作**：把 R73 的探针配方做成正式路径——环曲线 → `GeomProjLib.Curve2d` 生成 pcurve →
  `BRep_Builder.UpdateEdge(E, C2d, S, Loc, Tol)` → `MakeFace(surf, wire)` → `ShapeFix_Face`；
  四道闸：`BRepCheck` valid、面积 > 0、模型包围盒内、面自身包围盒间隙 ≤ 5%；
  **只有当一个样例的真实裁剪面比例 ≥ 阈值时才启用该样例的裁剪路径**（避免混合边界）。
- **验收**：每样例报"真实裁剪面 / 解析窗口面"可数比例；自由边/自由环必须下降，面数与包围盒漂移不得回退；
  不达阈值就如实记录"该样例不启用"。**成本**：1–2 天。

### P368 · 自由边/未闭合环进产品指标

- **动作**：`import_report` 增加 `free_edges`/`free_loops`（导入完成后一次性测，工具口径同源），
  状态行/部件树用 `import_sab` 的 Qt-free 措辞显示；R73 的跨文件计数回归测试作为护栏。
- **验收**：报告数字与 `tools/ref_family_diff.py` 独立复算一致；逐样例导入耗时不回退。**成本**：0.5 天。
