## E. 口径（R111 起沿用）

1. **尺寸单位三分**：约束里**数值**是米（求解器单位，也是 `con.dim` 写入的形式）；**表达式**是毫米
   （参数表语义）；**API/UI 传入**的是毫米。三者之间的换算只在 `sketchmode` 的两处（`dimensions` 与
   `_solver_rows`）发生，其它任何地方都不得再乘除 scale。
2. **半径两条路径都算数**：`(DIST, 圆心, 手柄, r)`（GUI 的"尺寸"命令）与 `(RADIUS, 圆心, r)` 都能驱动，
   写回一律以求解后的值为准；带 `radius` 约束时才把 `circles` 变量集交给求解器（否则不改 DOF 口径）。
3. **表达式存原文**：约束里保存 `2*d`，求解前解析成米；参数表变化走 `redrive_expressions()` 重解。
4. 每轮结束照旧：定向 + 全量回归 + 快照 `--check`（两种解释器）+ 同轮文档 + 提交推送。
