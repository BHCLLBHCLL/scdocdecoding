## 3. 边界（转 R123）

1. **锚点只能来自「选中的草图点」或手填 U/V**：不能在视口里直接拖一个锚点标记。
2. **改指向参数只能给参数名**：不能给带算式的目标（如 `param:2*d`），也不能改到参数表的表达式链。
3. **截图工具是「摆好姿势再拍」**：没有交互（`--demo` 三种固定场景）；工具栏/树/选项页之外的浮层（对话框、右键菜单）不入镜。
4. **截图依赖原生平台才有 3D**：离屏跑只有控件（视口黑），工具会如实报 `3d=False`。
5. **A-1 预览清单可勾选、A-4 尺寸驱动预览、A-5 拉前重解、A-7 三维模式选草图** 仍顺延；装配线仍在等 **B-1**。

## 4. 口径与纪律（R122 新增）

1. **界面要追上库层**：库层有的参数（锚点、目标类型），界面要么暴露要么明确不暴露；
   本轮把 R121 的三个库层能力全部接到界面（或明确记为边界）。
2. **默认值就是历史行为**：锚点默认仍是路径起点、U/V 为 0 时不写锚点 —— 新参数不得悄悄改变旧语义。
3. **GL 内容要单独取**（工具化）：窗口截图抓不到 GL 表面，必须从渲染窗口取像素再合成；
   这条写进工具文档，避免下一轮又拍出一张黑视口。
4. **工具要能离屏自检**：截图工具在离屏下也能跑完并产出 PNG（只是 3D 为空），
   所以它有一条不依赖显示器的测试。
