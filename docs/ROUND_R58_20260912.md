# R58 轮次交付记录（2026-09-12）

> 规则：每完成一轮改进即重新基线并产出**下一编号**的规划。本轮（R58）执行 P311：**圆锥折弯 / 轴向折弯**。
> 交付：圆锥折弯（旋转梯形，Pappus 闭式体积 + 中性层展开长）、轴向折弯（U 型槽：底板 + 两立边，闭式体积/轮廓/展开长）、圆锥面识别与折弯判定分离；记录两条实测教训与一个明确的遗留缺口。

## 1. 内核（`scdm/sheetmetal.py`）

| 项 | 实现 | 闭式 |
|---|---|---|
| `conical_bend(angle, t, height, r1, r2, k)` | 把**梯形截面**（半径 `r1..r1+t` → `r2..r2+t`）绕轴旋转 `angle`：内外表面都是锥面 | 体积 `= θ·((r1+r2)/2 + t/2)·t·h`（Pappus；实测 rel 3.5e-16） |
| `conical_bend_allowance(θ, r1, r2, k, t)` | 中间母线上的中性层展开长 | `= θ·((r1+r2)/2 + Kt)`（手算逐位一致） |
| `axial_bend(L, w, t, flange, θ, r, k)` | U 型槽：底板 + 两条立边；立边 = **圆环 ∩ 外侧象限盒**（精确圆柱布尔） | 底板 `L·w·t`，每条立边 `θ·(r + t/2)·t·L`（实测 rel 4e-16） |
| `axial_bend_allowance` | 单边折弯余量 | `θ·(r + Kt)`（与圆柱折弯同式） |
| `detect_conical(solid)` | 圆锥面识别：**采样点到轴距离**给两端半径 + 半锥角 + 轴向高度（v 参数不是轴向距离，方向还可能相反） | 半锥角 `atan(|r2−r1|/h)`、两端半径对 `(r1, r2)` / `(r1+t, r2+t)` |

**分工**：`detect_bends` 只认圆柱（既有行为不变），锥面走 `detect_conical`——把锥面当圆柱折弯会让 `unfold/flat_pattern` 用错展开长（纪律 60/67 的老失效模式）。

## 2. 两条实测教训

1. **用 `MakeRevol` 扫掠边截面做立边，fuse 会吃掉半个立边**：单独立边体积正确（`7.5398e-7` = Pappus），但 `fuse(底板, 立边)` 只有 `5.1609e-6`（应 `5.5540e-6`）——
   扫掠得到的是**面壳**而非干净实体，与底板布尔后体积对不上。改用**精确圆柱环 ∩ 象限盒**后逐位精确。
2. **象限取反了**：第一版把立边裁在**内侧**象限，立边落进底板轮廓里，fuse 只加了约一半（U 体积偏低 **12.46%**）；
   U 型槽的两条立边必须在底板轮廓**外侧**起弯。
3. （附带）**v 参数不等于轴向距离**：`detect_conical` 最初用 `ref_r + v·tan(semi)` 算半径，内外锥的两端半径互串（`0.022→0.03254`）；
   改为采样点算到轴的距离后，半径对正确（次序仍可能因面朝向相反，测试按"半径对"断言）。

## 3. 明确的遗留缺口（写入 R59）

U 型槽的 `detect_bends` 目前返回 **0**：立边的圆柱面片被**构造用夹持面**（象限盒的 `z=axis` 平面与 `y=边` 平面，都是过轴的径向面）和底板面共同包围，
唯一化后同向法线只剩一种（`uniq < 2`）→ 判不成折弯，`unfold` 报"未找到折弯"。
证据（实测邻接表）：内柱面 r=0.002 的相邻平面为 `(0,0,1)@0.002`（相切）与 `(0,0,1)@0.0`（径向）；外柱面 r=0.004 为 `(0,0,−1)@0.004` 与 `(0,0,1)@0.0`。
本轮**不修**（避免把构造面识别硬塞进检测器），列为 R59 首项：把构造夹持面从折弯配对里剔除或显式标记。U 型槽的展开长本轮由 `axial_bend_allowance` 闭式给出。
