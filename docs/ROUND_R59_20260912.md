# R59 轮次交付记录（2026-09-12）

> 规则：每完成一轮改进即重新基线并产出**下一编号**的规划。本轮（R59）执行 P315：**关闭 R58 遗留的 U 型槽折弯识别缺口**。
> 交付：轴向折弯补上**直段立边**（参数终于抵达几何）→ 识别/展开/闭式三者同时对齐；顺带把 `flat_len` 从"轴对齐包围盒近似"改成**顶点投影闭式**。

## 1. 根因（R58 的缺口不是检测器的错）

R58 的 `axial_bend` **校验并闭式使用了 `flange`，但从未把它建进几何**：立边只有 90° 环段，没有直段。
后果三连：①闭式（含 `flange`）与实体（不含）不一致；②立边在弯后**没有相切平面**，
圆柱面片只被两个**过轴的构造夹持面**夹住 → `detect_bends` 唯一化后 `uniq < 2`；③`unfold` 报"未找到折弯"。

**修法**：把直段立边按**弯后切线方向**建出来（不是永远竖直——只有 90° 才竖直）：
- 截面 = 出口处中面上 `t × flange` 的矩形（法向 = 出口处板面法向），沿 x 拉伸成棱柱；
- 出口方向 `d` 由扫掠角决定：左立边 `α₁ = −90°−θ`、右立边 `α₁ = −90°+θ`，`d` 取该角切线；
- 有了直段，立边外表面就是弯圆柱的**真正切平面** → `detect_bends` 正常配对（90°、r 正确）、`unfold` 走多弯链、展开长与手算逐位一致。

## 2. 顺带修掉的两处（都是实测暴露）

1. **夹持面必须过轴**：把"端平面"裁剪盒建在 `y=0`（世界坐标）时，对 `y=w` 那侧立边它**切在环的切线上**而不是过轴 →
   30° 折弯的扇形被切错，体积偏高 **1.29%**。改为盒的局部 `y=0` 平面取在 `(ay, az)`（即过弯轴）后，体积回到 2e-16。
2. **`flat_len` 的轴对齐近似**：原注释已写明"只对轴对齐棱柱成立"（用包围盒主轴分量当投影长度）。斜置立边（<90°）下它量错平板，
   展开长偏 **5%**。改为**把面的自身顶点投影到 `perp` 取跨度**——对任意平面精确，轴对齐时数值完全不变（既有 45 项钣金/成形测试全绿）。
3. **范围收紧**：`axial_bend` 角度限定 `(0, 90°]`——超过 90° 立边会折回底板，Pappus 求和会把重叠算两次（闭式不再成立），显式报错而不是给错数。
