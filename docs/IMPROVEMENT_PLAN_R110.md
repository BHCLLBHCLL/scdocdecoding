## E. 口径（R110 起沿用）

1. **焊接 = 约束 + 吸附**：先按容差找组，再把后出现的点移到组首，最后加 COINCIDENT（幂等）。
   只加约束不吸附在几何上仍不闭合，因此两者必须一起做；移动量 ≤ 容差并计入 `moved` 回报。
2. **UI 状态随撤销栈走**：所有压栈走 `_push_undo()`（含 `ui: {mode, sketch}`）；恢复期间用 `_applying_ui`
   守卫，禁止再次压栈（否则截断 redo）；无 `ui` 的历史快照按"三维模式"处理。
3. **GUI 测试持有 QApplication**：测试模块必须用全局变量持有 app（局部引用被 GC 会连带销毁所有控件）。
4. 每轮结束照旧：定向 + 全量回归 + 快照 `--check`（两种解释器）+ 同轮文档 + 提交推送。
