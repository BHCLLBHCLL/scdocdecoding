## 3. 边界（转 R128）

1. **点大小不随视图存盘**：只在本次会话生效（`settings` 里没记）→ 转 R128。
2. **改「点大小」不会立刻重画**：下一次 `_rebuild`（换模式/改文档）才生效，没接 `valueChanged`。
3. **A-6（三维模式选草图曲线）、A-7（交互式预览清单）** 仍顺延。
4. **逐行选择器只在选中 ≥2 行时出现**，单行仍用上面的单个选择器（一致但没做成同一控件）。
5. **C-8 余下两张参考图**（草图选择 / 修复）未补；装配线仍等 **B-1**。

## 4. 口径与纪律（R127 新增）

1. **预览要说全部**：预览的是「受影响的对象集合」，不是第一个；只说一个就是半个真相。
2. **预览承诺的 before 必须取回**：提交前把状态压进撤销栈，让「取消即不变」升级成「提交也能一步退回」。
3. **一个数一个来源**：点径进表；调用点再写数字字面量就是分叉（有源码级断言守着）。
4. **逐行输入要能逐行给**：手打分隔符是退路，界面必须能一行一个地挑。
5. **契约变了同轮改锁契约的测试**：`_preview_actor` → `_preview_actors` 由 R109 的 smoke 用例当场抓到，同轮更新。
