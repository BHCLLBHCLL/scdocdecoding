## 2. R11 工作项（P63–P68）

### P63 · 最后 4 个切分 + 1 个未重建面（最高优先）

- **动作**：对 2 个环面、2 个锥面逐面做与 R10 相同的逐候选诊断（采样 bbox vs 记录 bbox 逐轴差）；
  锥面切分多半是**圆锥面**没有解析周向窗口（只对圆柱做了 “圆 ∩ 投影凸包”），补上圆锥的解析窗口或改用采样判定；
  1 个未重建面按失败原因分类后补。
- **验收**：samplemodel2 面数 **1813 ± 0**、漂移 0.0%。
- **成本**：1 天。

### P64 · SampleModel4 的 35 个未重建面

- **动作**：①52 个 `ref` 型样条面 → 定位 ACIS `ref N` 引用表/延迟几何节（R8 已给四条排除证据；可用 SAT 的 71 个 `spline-surface` 极点做交叉定位）；
  ②其余可见面分类补。
- **验收**：SampleModel4 **177/177**；`tools/import_fidelity.py --strict` 退出 0。
- **成本**：2–3 天（①风险高）。

### P65 · 官方层级参与交互（积压三轮）

- **动作**：官方文档只读显示模型（part/component/layer → 显示分组），树勾选显隐与隔离。
- **验收**：勾选即时改变显示、几何不变；树与视口一致。
- **成本**：2 天。

### P66 · 大模型 GUI 可用性（积压三轮）

- **动作**：导入 → 视口构建 → 首次渲染的耗时/内存实测（samplemodel2/5），必要时按体或视锥懒装配。
- **验收**：打开到可交互 < 20 s；帧率与内存写入文档。
- **成本**：1–1.5 天。

### P67 · 特征族与梁焊件（广度，可分两轮）

- **动作**：孔向导/螺纹示意/凸台凹坑；6 种梁轮廓 + 沿草图或边生成。
- **验收**：闭式体积/包围盒/惯性矩断言。
- **成本**：4–6 天。

### P68 · 每轮维护（必做）

- **动作**：快照/CI（含 `--strict` 门禁）/口径同步；清理或接线 `import_sab.py` 中已不调用的诊断函数；**编号递增**。
- **成本**：0.5 天/轮。

## 3. 建议顺序

`P63 -> P65 -> P66 -> P64 -> P67`（P68 每轮收尾）

理由：P63 只差 4 个切分与 1 个面、路径已模板化（逐候选诊断），投入最小；P65/P66 是积压三轮的交互项；P64 的引用表是深水区；P67 最后扩广度。
