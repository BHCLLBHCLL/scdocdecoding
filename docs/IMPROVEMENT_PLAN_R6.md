## 3. R6 工作项（P37–P44）

### P37 · 导入保真度收尾（±0）

- **动作**：
  ①**面记录布局变体**：以 samplemodel3 为样本，对比其 face 记录的 token 序列与已知布局
  （t4=next/t5=loop/t6=shell/t8=surface），加变体分支（很可能缺少 attribs 前缀或带额外可选 token）；
  ②**B 样条面**：`_bspline_surface` 在 SampleModel4 的 34 个面上失败的原因（nubs/both 缺失或阶数解码）；
  ③**环面面**（5 个）与**平面多环**（内孔）重建；
  ④退化/自交环的容错（当前 `poly KernelError`）。
- **验收**：`tools/import_fidelity.py --strict` 退出 0（6/6 体数与面数完全一致）；上述每类都有单测。
- **成本**：2–3 天。

### P38 · 尺寸拖拽手柄（R5/P31 顺延）

- **动作**：视口尺寸对象手柄（沿法向拖动改 `Dimension.offset`）；拖动实时刷新 SVG/DXF；
  关联尺寸 stale 时给出可视提示。
- **验收**：拖动只改 offset（体积与标注值不变）；导出坐标随动；stale 提示可见。
- **成本**：1.5–2 天。

### P39 · 官方层级参与交互（R5/P33 顺延）

- **动作**：为"加载的官方文档"建立只读显示模型（part/component/layer → 显示分组），
  支持勾选显隐与隔离；不改动几何、不写回。
- **验收**：勾选 Part/图层即时改变显示；几何与体积不变；树与视口状态同步。
- **成本**：2 天。

### P40 · 特征族：孔/螺纹/成形（产品广度）

- **动作**：按官方 101 个 API 类型取首批子集：标准孔族（含沉头/锥沉已有）扩展为**孔向导**
  （直径/深度/攻丝标注）、螺纹示意（外形 + 螺距/旋向标注）、成形特征（凸台/凹坑/百叶/敲落，
  布尔 + 圆角近似）；命令 + 对话框 + 脚本 op + 特征历史 + 文档口径。
- **验收**：每特征闭式体积/包围盒断言；与官方外形对照清单；特征历史可重放。
- **成本**：3–4 天。

### P41 · 梁/焊件首批（产品广度）

- **动作**：梁轮廓库（L/T/I/管/圆/扁钢）+ 沿草图/边生成梁 + 焊接符号占位；
  .scdm 数据模型承载梁规格（截面/材料/朝向）。
- **验收**：6 种轮廓参数化生成；体积与惯性矩闭式断言；源曲线变化后梁随动。
- **成本**：3–4 天。

### P42 · 导入体验（告警可见 + 按部件兜底）

- **动作**：GUI 打开文件后状态栏/对话框展示 `import_warnings`（哪些部件未重建、是否网格兜底）；
  网格兜底改为"按失败部件按需触发"（需要 part↔facet 段映射：document.xml BodyDef ↔ facets 体段）。
- **验收**：打开 samplemodel2 显示"2/25 部件未重建"；按需兜底只补失败部件（新增体数 ≤ 失败数）。
- **成本**：1–1.5 天。

### P43 · 每轮维护（必做）

- **动作**：快照 `--update`/`--check`；CI 绿（含 `--strict` 保真门禁，库缺失时跳过）；
  文档口径同步；新命令必须"有行为测试或入台账"。
- **成本**：0.5 天/轮。

### P44 · 大模型 GUI 可用性（R5 只测了导入）

- **动作**：测"导入 → 视口构建 → 首次渲染"在 samplemodel2/5 上的耗时与峰值内存；
  必要时按视锥/体分组懒装配 actor；给出预算回归。
- **验收**：samplemodel2 打开到可交互 < 20 s（含导入）；拖动帧率可用（给出实测基线）。
- **成本**：1–1.5 天。

## 4. 建议顺序

`P37 -> P42 -> P38 -> P39 -> P44 -> P40 -> P41`（P43 每轮收尾）

理由：P37 收尾"读官方文件"的正确性（也是 `--strict` 门禁的前提）；P42 让用户立刻看得见
"读到了什么/丢了什么"；P38/P39 收交互尾巴；P44 保证大模型可用；P40/P41 再扩产品广度。

## 5. 纪律（延续 + R6）

1. 无官方哨兵不宣称"官方可开"；无逐字段 diff 不宣称"官方对齐"。
2. 任何"解析/导入成功率"必须写清口径路径（tokenizer ≠ 文档加载 ≠ B-rep 导入）。
3. 涉及 OCCT 几何算子的功能，测试必须含非法/极端参数路径。
4. 重写文件前核对 `totalLines`。
5. 解析器宽松化须配"合成流常量扫描 + 官方样本计数对拍"。
6. 官方数据功能的验收必须给"官方样本 vs 我方产物"的逐项计数表。
7. **新增**：性能改动必须先 profile 再动手（R5 的 50 s 曾被误判为"面太多"，实为一处兜底路径）。
8. **新增**：任何"兜底/降级"路径必须默认关闭 + 留痕（`import_warnings` 模式），
   禁止让用户误以为几何是完好的。
