## 2. R54 工作项（P295–P298）

### P295 · 钣金补项：角撑 gusset / 舌片 tab（最高优先）

- **动作**：面级成形两项，沿用 louver/knockout 的面框架 + prism/cut 路径；
  角撑=折角处的三角加料（体积闭式 = 三角形面积×板厚），舌片=局部凸出（体积闭式 = 面积×凸出高）。
- **验收**：闭式 + 非法 + 极端 + 回放 + **展开数值等价（纪律 60/67）**——与未成形件对照展开长/折弯数。
- **成本**：1 天。

### P296 · 图纸标注：引线 + 形位公差

- **动作**：引线标注（锚点吸附复用 `scdm.snaptools`）、形位公差框（符号/公差值/基准）；
  沿用 R52 的 undo 快照与导出（SVG/DXF）。
- **验收**：锚点吸附闭式（1e-12）+ 标注不入几何（不改体积/包围盒）+ 导出包含标注层 + undo 往返。**成本**：1 天。

### P297 · 可选补测（内存/帧率）

- **动作**：沿用 `tests/test_perf_budget.py` 口径补一次内存峰值与帧率基线。**成本**：0.5 天（可选）。
