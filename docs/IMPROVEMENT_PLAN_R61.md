## 2. R61 工作项（P323–P326）

### P323 · CAE 网格域首批：面网格 + 可数质量指标（最高优先）

- **动作**：对实体做面网格（复用 `scdm.facets` 的分面/焊接路径），给出**可数**指标：
  三角形面积和 vs `K.area`（离散误差显式给出）、退化三角形计数（面积 ≤ 阈值）、三角形数/顶点数、包围盒一致性。
- **验收**：面积和与 `K.area` 一致（rel 1e-6，并把网格离散误差写进断言）+ 退化三角形 = 0 + 非法（空形状/零尺寸）
  + 回放（同一实体两次网格化的计数逐位一致）。**成本**：1.5 天。

### P324 · 网格质量分布与报告

- **动作**：长宽比、最小角、雅可比下限的分布统计（min/p5/中位/p95/max）+ JSON/CSV 报告导出 + `mesh.report` 命令接线（含视口/状态栏提示）。
- **验收**：统计量与手算小网格一致（闭式）+ 报告往返 + 非法（全退化网格）+ 命令/状态接线。**成本**：1 天。

### P325 · 可选补测（内存/帧率）｜P326 · 每轮维护（必做）

- P325 沿用 `tests/test_perf_budget.py` 口径；P326 快照/CI/口径同步 + 编号递增 + 轮次记录同轮补齐（纪律 65）。
