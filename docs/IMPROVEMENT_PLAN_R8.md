## 3. R8 工作项（P49–P56）

### P49 · 保真度清零（最高优先）· 🟡 已开工未落地（见 `docs/ROUND_R8_20260912.md`）

- **动作**：
  ① `ref` 型样条面：在 SAB 中定位 ACIS `ref N` 的**引用表/延迟几何节**。已排除两条假设——实体下标（52 个 N 指向的实体种类随机）、与现有可建曲面共享（只命中 4/52）。
  下一步取证：用 SAT 的 71 个 `spline-surface` 顺序与极点值做**交叉定位**（把某个 `ref N` 面的 uv 窗口输入候选曲面，看哪一片能复现它的 bbox），再回 SAB 按同样的极点值搜存储位置。
  ② samplemodel2 的 +48 切分：整环 torus 的官方 bbox 疑有轴序互换，用 P46 的**窗口候选 + 面 bbox 自校验**选对 uv 读法，从而免布尔裁剪（当前 6 tori + 2 cones 被切成多片）。
- **验收**：`tools/import_fidelity.py --strict` 退出 0（6/6 体数+面数完全一致）；漂移不超过 1%；每类一条单测。
- **成本**：2–3 天。
- **进展（R8 首轮）**：①`ref` 取证完成（四条排除证据，见轮次文档）；②查出 samplemodel2 切分根因——**Bnd_Box 对周期曲面裁剪片膨胀 4.1%**，使正确 uv 窗口被 2% 阈值拒掉；
  三次修法（周期归一化 / 采样 bbox / 容差接受）均有实测数据但净收益为负，已全部回滚。
- **R9 新路线**：不再用 bbox 距离判窗口——**由边界曲线定窗口**（椭圆/直线边的参数区间或端点投影），或对环面用“环向解析窗口 + 管向量由边定”，避免整圈建面后裁剪。
  已试并否掉的四条路（周期归一化 / 采样 bbox / 容差接受 / 采样兜底）及其实测数据见 `docs/ROUND_R8_20260912.md`，R9 不要重复。

## 4. 建议顺序

`P49 -> P50 -> P51 -> P52 -> P53`（P54 每轮收尾；P55/P56 视预算插入）

理由：P49 是唯一还挡着 `--strict` 退出 0 的账，且已完成排除性取证，继续推成本最低；P50/P51 是积压两轮的交互项且互相独立；P52/P53 最后扩产品广度。

## 5. 纪律（延续 + R8 新增）

1. 无官方哨兵不宣称官方可开；无逐字段 diff 不宣称官方对齐。
2. 解析/导入成功率必须写清口径路径（tokenizer 不等于文档加载，不等于 B-rep 导入）。
3. OCCT 几何算子的功能测试必须含非法/极端参数。
4. 重写文件前核对 `totalLines`。
5. 解析器宽松化须配合成流常量扫描 + 官方样本计数对拍。
6. 官方数据功能的验收必须给逐项计数表。
7. 性能改动先 profile。
8. 兜底/降级默认关闭 + 留痕。
9. 解码器不得依赖固定 token 下标（官方同版本存在布局变体），必须按角色位次或种类定位。
10. 导入类功能的验收必须同时给数量与几何位置（bbox）两个判据。
11. 同一几何量若有两个独立来源（曲线参数/顶点表），必须交叉校验，冲突时以点表为准并留痕。
12. 包围盒判据要分层：面级严、模型级宽兜底、退化轴跳过。
13. **新增**：官方二进制布局先用**官方工具转文本对拍**再写解码器——P46b 的 `nubs` 布局靠 SAT 文本一次定死（度数、Σmult、极点维度），比试错快一个数量级。
14. **新增**：解码口径不确定时用**候选取值 + 记录 bbox 自校验**（P46 的 uv 窗口、P46b 的极点存序已两次复用）。
15. **新增**：跨节引用（`ref`）类问题先做**排除性取证**并把已排除假设写进文档，禁止下一轮重复试错。
16. **新增**：规划与轮次文档**编号随轮次递增**，不得原地改写旧编号文件。
