## 1. 报告结构（`SR.build_report(kdoc, scale)`）

| 段 | 内容 | 可数判据 |
|---|---|---|
| `counts` | 载荷/支撑/接触/标记/网格体/实体 条数 | **逐条等于** `len(kdoc.sim.*)`（相等断言，不是"差不多"） |
| `loads/supports/contacts/markups` | id/类型/实体/面/向量/量值/位置 | 顺序与 id 与模型一致 |
| `meshes` | 每个有网格的实体：三角形数/顶点/退化/面积误差/**门槛是否通过 + 违规条数** | 门槛严格化后 `gates_ok=False`、违规 **12** 条 |
| `materials` | 名称/材料/材料名/质量/体积 + `total_mass_g` | 改材料 → 质量按**密度比**变化（派生重算，纪律 77） |
| `blockers / blocker_text / ready` | 缺网格 / 门槛未过 / 缺载荷 / 缺支撑 | blocker 是**清单**；`ready ⇔ blockers 为空` |

## 3. 新增纪律

84. **同一事实只有一个来源**。摘要文本与报告必须从**同一个模型快照**派生——
   本轮把状态栏从 `sim.summary()`（另一条拼装路径）切到报告文本 `report_text(rep)`，
   摘要只作为报告里的一个字段；否则"摘要说 2、报告说 3"这类错位迟早出现。
