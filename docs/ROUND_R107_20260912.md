## 3. 本轮发现的一个真实坑（已入册 R108）

分开画的线段只靠坐标"碰"在一起，**没有 COINCIDENT 约束**：一求解它们各自移动 → 轮廓被撕开 →
`sketch_loops` 找不到闭环。系统的表现是**诚实**的（同步报告「第 1 个闭环已不存在」、几何一动不动），
但用户会感觉"改个尺寸图就没了"。修法：绘制/捕捉到端点时自动记 COINCIDENT，或求解时按容差焊接端点。

## 4. 边界（转 R108）

1. **自动焊接**（上条）：绘制时闭合点自动 COINCIDENT / 求解前按容差合并。
2. **半径尺寸**（`radius`）未开放：圆的尺寸目前走"圆心 → 半径点"的 DIST（就是 `con.dim` 建的那种），
   真半径变量需要求解器的 `circles` 映射。
3. **尺寸表达式**（`w = 2*d`）：求解器支持 `param_table`，UI/API 还没接。
4. **拉伸选项**（反向/两侧/到面）仍未接入 `sketch` 特征。
5. 多闭环共用高度没有专门的 UI（每个实体自己的 `height` 可独立编辑 ✓）。
