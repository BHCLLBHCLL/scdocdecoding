# R108 轮次交付记录（2026-09-12）——A-1 自动焊接 + A-4 拉伸选项

> 两项都在"草图 → 实体"这条链上，验收都是闭式体积 + 包围盒位置。

## 2. 验收实测

| 项 | 实测 |
| --- | --- |
| 焊接 | 4 条分开画的线 → 加 **4** 条 COINCIDENT（第二次 0 条，幂等）；坐标一字不动；闭环仍 **1** 个 |
| 只焊顶点 | 圆心与线端点同坐标 → 加 **0** 条（圆心的 kind 不是 vertex） |
| **不焊的后果（诚实锁定）** | 直接求解（R107 路径）→ `sketch_loops == []`、同步报「闭环已不存在」、体积**一动不动**（4e-07） |
| **焊接后驱动** | `set_dimension` 上报 `welded=4`、`dof=0` → 宽 10→20mm → 闭环仍在 → 体积 **8e-07**（rel 1e-6）、`can_replay` 真 |
| 三种落座 | 同一草图 10×8×5mm：one → z ∈ [0, 0.005]；**symmetric** → z ∈ [−0.0025, +0.0025]；**reverse** → z ∈ [−0.005, 0]；三者体积都是 **4e-07**；各自的 `mode` 记进特征、`can_replay` 真 |
| 高度联动 | 三种模式下改高度 5→8mm → 体积 **6.4e-07**、厚度 0.008，对称体仍以草图面为中心（−0.004..+0.004） |
| 非法方式 | `place_extrusion(mode="sideways")` → ValueError |
| GUI | 勾选 Pull 的「对称」→ `sketch.pull` → 包围盒 **±0.0025**、特征 `mode == "symmetric"`、退出草图模式 |

## 3. 顺带修掉的一个真实缺陷

`read_points` 里圆心取 `c[1][2]` —— 但圆心常是 **2 元组** `(x, y)`，直接 `IndexError`（R108 的焊接测试第一次就踩到）。
现在按长度取值（缺 z 记 0），圆弧草图的求解器变量读取不再抛异常。

## 4. 边界（转 R109）

1. **到面**只在 GUI 里做（需要选中面 + 视口）；库层 API 仍是"给高度"，没有 `to_face` 参数。
2. **焊接容差**默认 1e-9 m（1 nm，即"坐标相同"）；跨线条的"看起来相接但差 0.1mm"不会被焊（SpaceClaim 会按捕捉容差焊）——按捕捉容差焊接列入 R109。
3. **半径尺寸**（`radius`）仍未开放（需求解器 `circles` 映射）；圆的尺寸目前走"圆心→半径点"的 DIST。
4. **尺寸表达式**、**草图镜像/阵列**、**模式进撤销栈**、**活动草图持久化**仍在 R108 计划里未做（转 R109）。
