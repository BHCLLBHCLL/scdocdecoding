## 2. R10 工作项（P57–P62）

### P57 · 环面切分清零（最高优先，R9 直接续做）

- **已知**：切分从 18+2 降到 **14+2**，其中 **13 个集中在 samplemodel2 的模型 2**（同为 torus，采样 7 点仍判不过）。
- **动作**：对模型 2 的环面逐面导出“采样 bbox / 记录 bbox”逐轴差值，判定属于①网格密度（对该模型用 13 点）还是②窗口读法（u/v 互换、符号翻转）；
  若都不是，改走**边界曲线定窗口**（椭圆/直线边的参数区间或端点投影），彻底摆脱 bbox 距离判据。
- **验收**：samplemodel2 面数回到 **1813 ± 0**；漂移 0.0%；导入 ≤ 10 s。
- **成本**：1–2 天。

### P58 · SampleModel4 未重建的 35 面

- **动作**：①52 个 `ref` 型样条面：按 R8 的四条排除证据继续定位 ACIS `ref N` 的引用表/延迟几何节（可用 SAT 的 71 个 `spline-surface` 极点做交叉定位）；

- **验收**：SampleModel4 **177/177**；`tools/import_fidelity.py --strict` 退出 0。
- **成本**：2–3 天（①风险高）。

### P59 · 官方层级参与交互（R8/P50 顺延）

## 3. 建议顺序

`P57 -> P59 -> P60 -> P58 -> P61`（P62 每轮收尾）
