## 2. R4 排序依据（本轮新增证据）

1. **P19 缩范围**：约束符号/尺寸可视化、3D 草图、extend 未做 —— 草图是参数化建模入口，价值最高。
2. **P16 只覆盖单体特征**：阵列/镜像/合并/分割会增删实体，需要**文档级特征模型**；当前
   `FeatureStack` 是"单体重放"，装不下。
3. **装配配置缺失**：官方 `AssemblyConfigurationsRibbonTab`；我们连"配置"概念都没有
   （可见性/抑制集无法命名保存）。
4. **工程图尺寸无交互**：P17 只有数据模型 + 导出；视口拖拽、与边/面关联未做。
5. **官方库大模型未见 GUI 实测**：samplemodel2（37 体/1813 面）SAB tokenize 3.46 s，
   `load_scdoc` 全链与视口三角化耗时未知；80 体样例（samplemodel5）同理。
6. **只读打开保真度**：`load_scdoc` 返回 doc/models/fac/render，但 GUI 结构树只显示 bodies，
   官方的 layer/命名选择/caption 未进入界面。

## 3. R4 工作项（P21–P28）

### P21 · 草图约束可视化 + 3D 草图（P19 收尾）

- **动作**：约束符号（H/V/∥/⊥/=/⊙）+ 尺寸线在草图平面的画布渲染（scene 增加 `_constraint_actor`）；
  尺寸值随求解更新；新增 3D 草图模式（在任意平面绘制、相机贴法向已有）。
- **验收**：offscreen 断言约束 actor 数 == 约束数；改尺寸后 actor 文本更新；3D 草图可拉伸成体。
- **成本**：2–3 天。

### P22 · 文档级特征模型（多体特征 + 特征树交互）

- **动作**：把 `FeatureStack` 升级为文档级特征列表（特征可产出/消费多个实体：阵列、镜像、合并、
  分割）；特征树支持选中/删除/顺序重放（删除后回放其余特征）；持久化进 .scdm。
- **验收**：参数改动后"孔 + 阵列 + 抽壳 + 镜像"链完整重放（体积闭式）；删除中间特征后重放不崩、
  体数正确；.scdm 往返保持特征列表。
- **成本**：3–4 天（需设计）。

### P23 · 装配配置（Configuration）

- **动作**：`KernelDoc.configurations`（命名 + 每组件可见性/抑制 + 可选 transform 覆盖）；
  GUI 组件页新增"配置"命令组；随 .scdm 持久化；导出时按当前配置写 component 可见性。
- **验收**：两配置（全展开/隐藏某组件）切换后视口可见性与树状态同步；项目重开后配置保持。
- **成本**：1.5–2 天。

### P24 · 工程图尺寸交互（拖拽 + 关联）

- **动作**：视口内尺寸对象手柄（拖动改 `Dimension.offset`）；尺寸与边/面关联（选择边生成尺寸，
  几何变化后仍指向同一拓扑）；SVG/DXF 随拖动更新。
- **验收**：拖动不改几何（体积恒定）且标注值不变；关联边在被拉动后标注值随几何更新（或明确标记失效）。
- **成本**：2–3 天。

### P25 · 大模型可用性（性能与内存预算）

- **动作**：实测 `load_scdoc` + `import_scdoc_bundle` + 视口三角化在 samplemodel2/5 上的耗时与峰值
  内存；加进度反馈/懒加载（先 facets 后 B-rep）、视口按视锥裁剪；写入性能回归预算测试（宽松上限）。
- **验收**：samplemodel2 全链 < 15 s、samplemodel5 < 20 s（或给出实测基线 + 预算）；GUI 不冻结。
- **成本**：1–2 天 + 测量。

### P26 · 钣金折弯表 + 展开图标注

- **动作**：折弯表（材料/厚度 → K/R 表）；展开图 DXF 增加折弯线（dashed）与折弯方向/角度标注；
  `bend_relief` 与卷边组合到展开图。
- **验收**：给定折弯表的 K 值参与展开长度（对拍手算值）；展开图含折弯线层与角度文本。
- **成本**：1–2 天。

### P27 · 只读打开保真度（官方文档树）

- **动作**：`load_scdoc` 暴露 layers/captions/named selections 到 Session；左栏结构树按官方
  Part/Component 层级显示（而非平铺 bodies）；属性页显示 caption/layer/material 只读信息。
- **验收**：打开 samplemodel2 后树节点数与 document.xml 的 PartDef/ComponentDef 数一致；层名可见。
- **成本**：1.5–2 天。

### P28 · 每轮维护（必做）

- **动作**：快照 `--update` + `--check`；CI 保持绿；文档口径（gap/NYI/ROUND）同步；
  新命令必须"有行为测试或入台账"。
- **成本**：0.5 天/轮。

## 4. 建议顺序

`P21 -> P22 -> P23 -> P24 -> P25 -> P26 -> P27`（P28 每轮收尾）

理由：P21 补完 R3 缩范围且直接服务参数化主线；P22 是 P16 的结构性升级（决定"参数驱动"能否覆盖
阵列/镜像）；P23 是官方页签中我们唯一完全没有概念的域；P24/P25 是既有功能的质量与规模；P26/P27 收尾。

## 5. 纪律（延续 + R3 新增）

1. 无官方哨兵不宣称"官方可开"；无逐字段 diff 不宣称"官方对齐"。
2. 任何"解析成功率/覆盖率"结论必须写明口径路径（SAB tokenizer ≠ 文档加载 ≠ GUI 导入）。
3. 涉及 OCCT 几何算子的功能，测试必须含非法/极端参数路径（防原生崩溃逃逸）。
4. **新增**：重写文件前核对 `totalLines`（R3 曾因 read limit 截断测试文件，丢失 16 项测试）。
5. **新增**：解析器的宽松化必须配"合成流常量扫描 + 官方样本计数对拍"两类测试（P13 的双保险）。
