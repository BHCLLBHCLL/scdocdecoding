## 2. 已修的一类：缝边不是缺口（口径修正）

周期面（圆柱/圆锥/球/环）的**缝边**如果只被同一个面用一次，在邻接表里看起来就是"自由边"。实测 0 / 18 / 73 条，
此前全部被算进"未封闭"。现在拆开：`free_edges`＝所有单面边，`open_edges`＝**真缺口**（缝边剔除）；
两个仪器（`ref_family_diff` / `free_edge_report`）都走 `scdm.kernel` 的同一份实现（纪律 84）。

## 3. 真缺陷：pythonocc 的视图不能跨容器生命周期

第一版把祖先表（`TopTools_IndexedDataMapOfShapeListOfShape`）里的列表直接返回给调用方，函数返回后容器被回收，
调用方读到的是**空列表**（`Size() == 0`，不报错）——于是"缝边"全部被判成"不是缝边"（0 条），
而自由边计数因为全 0 反而"看起来正常"。同一段代码在**同一个进程里**先建表再用就没问题，所以它隐藏了很久。
处置：`edge_face_counts` 在容器存活期间把 `(边, 面数, 属主面)` 全部取出（就不再有悬空引用）。

## 4. 新增纪律

88. **pythonocc 的返回值可能是视图**：`FindFromIndex/First/...` 交出的句柄只在容器存活期间有效，
    容器回收后读到 0（不抛异常）。凡是要跨函数边界带出容器内容，必须在容器存活期间**物化**成 Python 值。
    R75：祖先表视图让 73 条缝边静默变成"不是缝边"，且计数为 0 时"看起来正常"。
