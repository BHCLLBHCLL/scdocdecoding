## 3. R5 工作项（P29–P36）

### P29 · 官方 B-rep 导入保真度（最高优先）

- **动作**：以 6 个官方样例为对拍基准，逐层定位 `import_sab.import_model/_faces_from_model`
  与 `topology.face_loops_polygons/loop_polygon` 的偏差来源（环闭合失败被丢弃？曲面面被跳过？
  重复重建合并/丢弃？）；建立"导入保真度报告"（每样例 SAB 体/面/边 vs 导入后体/面/边）。
- **验收**：6/6 样例 **体数完全一致、面数一致（±0）**；@tests/test_perf_budget.py` 增加保真度断言。
- **成本**：1–2 天（含定位；可能需要环恢复策略：基于 coedge 顺序的闭合 + 顶点回退）。

### P30 · 导入性能（profile → 优化）

- **动作**：profile samplemodel2 导入；消除逐面重复拓扑遍历/重复 OCC 对象构造（缓存 face→edges、
  批量 sew、必要时对曲面面走 facets 兜底而非精确 B-rep）；确保无 O(n²)。
- **验收**：samplemodel2 < 15 s、samplemodel5 < 10 s、samplemodel3 < 5 s（本机，预算回归测试）。
- **成本**：1 天（依赖 P29 的正确性基线）。

### P31 · 工程图尺寸拖拽手柄（P24 收尾）

- **动作**：视口内尺寸对象手柄（沿法向拖动改 `Dimension.offset`）；拖动实时更新 SVG/DXF；
  关联尺寸在几何变化后标记 stale 时给出提示。
- **验收**：拖动仅改 offset（体积不变、值不变）；导出文件坐标随拖动变化；stale 提示可见。
- **成本**：1.5–2 天。

### P32 · 特征树交互（P22 收尾）

- **动作**：左栏特征节点右键菜单：删除/重建（模型层 `FeatureHistory.remove_at` 已有）、
  重放失败提示；删除后自动重放并刷新体。
- **验收**：删除中间特征 → 体数/体积按解析值变化且无异常；重放失败有明确状态文本。
- **成本**：1 天。

### P33 · 官方文档树参与交互（P27 收尾）

- **动作**：官方 Part/Component 节点支持可见性勾选与隔离显示（只读几何 + 显示状态），
  图层勾选控制面片显示（facets 按 body 分组）。
- **验收**：勾选 Part 隐藏其面片；图层勾选影响显示；不改动几何。
- **成本**：1.5 天。

### P34 · 特征族：标准孔/螺纹/成形（广度项）

- **动作**：按官方 101 个 API 类型的首批子集实现：沉头/锥沉（R3 已有）、螺纹示意（外形 + 螺距标注）、
  凸台/凹坑/百叶/敲落（布尔+圆角近似）；命令 + 参数对话框 + 脚本 op + 特征历史。
- **验收**：每特征闭式体积/包围盒断言；官方外形对照清单；特征历史重放。
- **成本**：3–4 天。

### P35 · 梁/焊件首批（广度项）

- **动作**：梁轮廓库（L/T/I/管/圆/扁钢）+ 沿草图/边生成梁 + 焊接符号占位；写回 .scdm 数据模型。
- **验收**：6 种轮廓截面参数化生成、体积/惯性矩闭式断言；梁随源曲线更新。
- **成本**：3–4 天。

### P36 · 每轮维护（必做）

- **动作**：快照 `--update`/`--check`；CI 绿；文档口径（gap/NYI/ROUND）同步；新命令必须
  "有行为测试或入台账"。
- **成本**：0.5 天/轮。

## 4. 建议顺序

`P29 -> P30 -> P31 -> P32 -> P33 -> P34 -> P35`（P36 每轮收尾）

理由：P29/P30 是"打开官方文件"的正确性与速度（产品可信度）；P31–P33 收掉三处交互尾巴，
让已有能力"可操作"；P34/P35 才开始扩产品广度——广度必须建立在可信的读取与交互之上。

## 5. 纪律（延续 + R4 新增）

1. 无官方哨兵不宣称"官方可开"；无逐字段 diff 不宣称"官方对齐"。
2. 任何"解析/导入成功率"结论必须写清口径路径（tokenizer ≠ 文档加载 ≠ B-rep 导入）。
3. 涉及 OCCT 几何算子的功能，测试必须含非法/极端参数路径。
4. 重写文件前核对 `totalLines`。
5. 解析器宽松化须配"合成流常量扫描 + 官方样本计数对拍"。
6. **新增**：涉及官方数据的功能，验收必须给"官方样本 vs 我方产物"的**逐项计数表**（P25 的做法），
   而不是"不报错即通过"。
