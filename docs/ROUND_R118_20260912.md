## 3. 边界（转 R119）

1. **修复动作只有两个**：尺寸只能冻结（不能改指向另一张草图），其余只能整条删除（不能改指向）。
2. **冻结的量纲**：尺寸冻结用的是「当前几何测出来的值」，所以冻结前后体积不变；若几何本身已被改坏，冻结只是把它固化。
3. **`repair.refs` 无确认**：修全部是一键的（可撤销）；没有逐条复核界面。
4. **体检行只覆盖尺寸/配合/配置/实例的定位**：命名选择与组目前只给状态文字。
5. **A-4 尺寸驱动预览、A-5 拉前重解、A-6 锚点可控、A-7 三维模式选草图** 仍顺延；装配线仍在等 **B-1**。

## 4. 口径与纪律（R118 新增）

1. **诊断的下一步是修复**：报告一条悬空不算完成，要给出**能执行**的动作，并说明为什么别的动作不行
   （「可用：freeze」而不是「不支持」）。
2. **删除要按值，不按下标**：批量修复时按下标删会让后面的条目移位（本轮实现里所有 `drop` 都按值找）。
3. **冻结 = 把当前几何写成数**：不猜、不取零；冻结前后几何逐字节不变。
4. **连线和标记必须同一口径**：只有 `state=redundant` 的标记才连线，否则「标记说它是冲突、连线说它是副本」自相矛盾。
