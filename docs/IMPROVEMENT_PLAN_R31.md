## 2. R31 工作项（P181–P186）

### P181 · 孔族收尾（最高优先）

- **动作**：①螺纹示意——`Feature` 记录 `(type="hole_tapped", nominal, pitch)`，视口画牙型示意线（不参与布尔）；
  ②命令 `prep.hole` 增加“攻丝”选项与公称/螺距输入；③脚本 op 与特征历史回放覆盖攻丝孔。
- **验收**：回放后体积与直接调用一致；示意线存在但不改变体积；命令级行为测试覆盖。**成本**：1–1.5 天。

### P182 · 成形族（凸台/凹坑/百叶/敲落）

- **动作**：按 R30 的“**闭式体积 + 非法参数拒绝 + 极端参数**”模板逐个实现（凹坑/百叶为钣金成形，需与 `sheetmetal.py` 协同）。
- **验收**：每个成形特征一条闭式断言 + 一条非法参数断言。**成本**：1.5–2 天。

### P183 · 梁/焊件首批｜P184 · 图面尺寸第二批（多选/吸附/undo）｜P185 · 可选补测（内存/帧率）

### P186 · 每轮维护（必做）：快照/CI/口径同步；编号递增；关键功能完成即提交推送。
