## 2. R32 工作项（P187–P192）

### P187 · 攻丝孔接线（最高优先，P181 收尾）

- **动作**：①`Feature` 增加 `hole_tapped`（记录 nominal/pitch）；②`prep.hole` 命令加“攻丝”选项与两个数值输入；
  ③脚本 op/回放：`record("prep.hole", tapped=True, nominal=..., pitch=...)` 后重放体积一致；④视口用 `thread_lines` 画示意（不参与拾取）。
- **验收**：回放体积 == 直接调用体积（rel 1e-6）；示意存在但 `K.volume` 不变；命令级行为测试 1 条 + 回放测试 1 条。
- **成本**：1–1.5 天。

### P188 · 成形族（凸台/凹坑/百叶/敲落）

- **动作**：套用“闭式体积 + 非法参数 + 极端参数”模板；凹坑/百叶与 `sheetmetal.py` 协同。
- **验收**：每个特征一条闭式断言 + 一条非法参数断言。**成本**：1.5–2 天。

### P189 · 梁/焊件首批｜P190 · 图面尺寸第二批｜P191 · 可选补测（内存/帧率）

### P192 · 每轮维护（必做）：快照/CI/口径同步；编号递增；关键功能完成即提交推送。
