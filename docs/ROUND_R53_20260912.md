## 1. 折线梁与焊件模型（`scdm/beams.py`）

| 项 | 实现 |
|---|---|
| `beam_polyline(profile, points)` | 每段一个**独立实体**（成员）；先在段级别校验（≥2 点、相邻点不重合） |
| 为什么不 fuse | 两段在接头处只共点/共线，fuse 会产生**非流形边**；焊件成员本就是独立实体，闭式因此是**纯和** `Σ A×段长`，没有布尔去重可推理错 |
| `Weldment(profile, dims, material)` | 成员共享截面与材料；`set_section()` 改截面后**所有成员随动**（不缓存形状）；`remove_member()` 连带删除该成员的符号 |
| 闭式 | `total_volume() = area() × total_length()`；单成员 `shape(name)` 用 `beam_along` 精确构建 |
| `WeldSymbol` | 类型（fillet/groove/plug/spot/seam）+ 尺寸/长度/间距/所属成员/位置；**只做元数据，不建几何**（同螺纹示意策略）；校验：类型合法、尺寸 > 0、长度/间距非负、**断续焊必须给长度**、指向不存在的成员报错 |
| 持久化 | `to_dict/from_dict` 全字段往返 |
