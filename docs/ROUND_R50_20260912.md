## 1. 内核 `K.knockout(solid, face, diameter, web, web_count)`

| 项 | 实现 |
|---|---|
| 环切 | 环形刀 = 外圆柱 `D` **减**内圆柱 `D−2·web`（精确圆柱布尔，非多边形近似）；`cut` 掉环缝 |
| 补筋 | 每条筋 = `prism` 造的扇形棱柱 ∩ 环 ∩ **原材料**；扇形角 `dθ = 2π·web²/环面积` ⇒ **每条筋面积恰为 `web²`** |
| 闭式 | `切除面积 = π(R²−r²) − web_count·web²`（`R = D/2`、`r = R − web`），`切除体积 = 面积 × 板厚`（沿面法向，同百叶） |
| 面框架 | 与百叶同一条 `_face_frame` + 扇形棱柱路径，法向任意（底面/斜面板同一路径） |
| 非法 | `web ≥ 直径`（本轮判定项）、`web ≥ 半径`（环缝吃掉整片）、`web ≤ 0`、`筋数 < 1`、`直径 ≤ 0`、`筋数×筋宽² ≥ 环面积`（筋盖满环缝，闭式会转负） |

> **为什么筋要与原材料求交**：筋若取“整条扇形棱柱”，在非等厚/带翻边实体上会沿法向长出鳍片——
> R50 实测 90° 弯板上体积反涨 1.4e-8 m³，闭式对不上；求交后筋只填本墙厚，弯板上闭式回到 rel 1e-13。

## 2. 展开守卫修复：`detect_bends` 不再把敲落片壁当折弯（纪律 60 的真实收获）

- **现象**：敲落片壁（`D−2w` 圆柱）与孔壁（`D` 圆柱）**同轴**，被 `coax` 归为一组；
  它们垂直于轴的“相邻平面”只有**过轴的径向筋平面** ⇒ 该柱面组被判成**第二条折弯**
  （实测 96.4°、r 2.4 mm、t 0.6 mm）。
- **后果**：90° 弯板成形后 `detect_bends` 返回 2 条折弯，`flat_pattern` 展开长
  **54.46 → 59.52 mm（+9%）**，而且**不抛异常**——只写“不抛”的兼容性断言挡不住它。
- **修复**：柱面候选要求**至少一个**相邻平面的“平面到轴距离”≈ 半径（真折弯两侧平板与柱面**相切**；
  径向平面过轴，距离 ≈ 0）。判据是**组级**的：只有当**全部**相邻平面都过轴时才否决，
  因此端面为径向切面的卷曲薄板仍是折弯（多弯链/链序测试原样通过）。
