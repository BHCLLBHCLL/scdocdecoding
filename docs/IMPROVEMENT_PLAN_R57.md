## 2. R57 工作项（P307–P310）

### P307 · 图纸标注第二批：样式 + 基准体系（最高优先，R56/P304 顺延）

- **动作**：引线箭头样式（实心/空心/无）、字高与颜色、基准符号（A/B/C 与基准目标）、公差框多格（复合公差）；
  导出（SVG/DXF）同步层与属性；吸附/undo 不回归。
- **验收**：样式字段往返一致 + 导出含样式属性 + R52/R55 全部图面测试仍绿。**成本**：1 天。

### P308 · 圆锥折弯 / 轴向折弯

- **动作**：圆锥折弯（母线为斜线的旋转面，展开长用中性层弧长闭式）与轴向折弯（沿圆筒轴向折边）；
  与 `detect_bends`（圆柱）区分：圆锥面单独识别，避免又一次"伪折弯"（纪律 60/67）。
- **验收**：展开长闭式（圆锥的 `θ·(R+Kt)` 推广）+ 非法 + 极端 + 回放 + 与既有圆柱折弯共存不变。**成本**：1.5 天。

### P309 · 可选补测（内存/帧率）｜P310 · 每轮维护（必做）

- P309 沿用 `tests/test_perf_budget.py` 口径；P310 快照/CI/口径同步 + 编号递增 + 轮次记录同轮补齐（纪律 65）。
