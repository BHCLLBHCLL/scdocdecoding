# R69 轮次交付记录（2026-09-12）

> 规则：每完成一轮改进即重新基线并产出**下一编号**的规划。本轮（R69）执行 P352：**图纸尺寸链与公差叠加**。
> 交付：`scdm/dimchain.py`（链判定 + 两条叠加公式 + 总尺寸）、单一标注来源 `D.dim_text`、图纸对话框"尺寸链"入口、SVG/DXF 同步。

## 1. 链与叠加（闭式）

| 量 | 公式 | 实测 |
|---|---|---|
| 链和 | `Σ value_i` | 20+30+50 = **100.0 mm**（rel 1e-12） |
| 跨度 | 首段起点 → 末段终点（**mm**，与 value_mm 同单位） | 0.10 m → 100.0 mm；`mismatch = 0` |
| 极值叠加 | `Σ|tol_i|` | 0.1+0.2+0.3 = **0.6**（rel 1e-15） |
| 统计叠加 | `sqrt(Σ tol_i²)` | `sqrt(0.14) = 0.3741657` |
| 总尺寸 | `chain_dimension()` → 一个带叠加公差的 `Dimension` | value 100.0、tol 0.6、a/b 取首末端点、标注 `100.0 ±0.6` |

**单位坑（本轮实测）**：`Dimension.a/b` 是**视图米**而 `value_mm` 是**毫米**——第一版直接相减，把每条合法链都判成"断口 99.9 mm"。
现在链判定内部统一用 mm（`MM = 1000`），断口与跨度都与 `value_mm` 可比。

## 2. 可数判定（不是布尔）

`check_chain()` 返回 `{ok, axis, order, sum, span, mismatch, breaks, violations, count}`：
- **断口**逐条给出 `{after, at, gap}`（索引 + 缺口 mm）；**方向违规**逐条给出 `{index, reason:"axis"}`；
- 顺序是**推导**出来的（按起点排序）——打乱输入仍然成链（测试断言 `order == [1,2,0]`）；
- 断链**不能**生成总尺寸（`chain_dimension` 报错），但判定本身仍给出部分和与缺口。

## 3. 单一标注来源（纪律 84 的延续）

`D.dim_text(d)` = 值 + 公差 + 失效标记，**画布 / SVG / DXF 三处共用**：
R69 之前三处各拼一次字符串，公差只会在某处出现；现在 `30.0 ±0.2` 在 SVG 与 DXF 里逐字一致（测试断言两处都在）。
