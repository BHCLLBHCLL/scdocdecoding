## P49① `ref` 型样条面：排除性取证结果

52 个 `ref` 型样条面的曲面数据**不在本 part 的实体表里**，四条证据：

1. SAT 侧同样是 `spline-surface ... { ref N } F u0 F u1 F v0 F v1 #`——官方文本也只写引用号 + 4 个 uv 值，几何不在原处；
2. `ref` 的 N **不是实体下标**：52 个 N 指向的实体种类随机（body/face/loop/coedge/point/ellipse/cone…），无一是曲面；
3. 全模型：71 个 `spline` 实体中 19 个带 `exactsur` 簇、52 个只有 `ref`，且 52 个都被面引用；36 个 `exactsur` 簇的拥有者是 pcurve(26)/intcurve(10)，属曲线级曲面；
4. **曲面共享假设亦排除**：用 26 个可建曲面按 uv 窗口 + 面 bbox 自校验去匹配 52 个 `ref` 面，只命中 4 个。

→ 下一步（R9 首选）：在 SAB 中定位 ACIS `ref N` 的**引用表/延迟几何节**；可用 SAT 的 71 个 `spline-surface` 顺序与极点值做交叉定位。

## P49② samplemodel2 的 +48 切分：查出根因，但三次修法均未落地

**根因（已实测）**：窗口校验用的是“建面 bbox 与记录 bbox 的距离”，而 `Bnd_Box` 对**周期曲面的裁剪片会膨胀**——
实测一个四分之一管环面片在两个轴上多出 0.043（约该面尺寸的 **4.1%**），恰好超过 2% 的接受阈值，
于是**正确的 uv 窗口被拒**，退回布尔裁剪 → 一个面被切成多片（samplemodel2 多出 48 个面、漂移 0.6%）。
旁证：把窗口 `(0, 2π) × (0, π/2)` 在曲面上**采样**，得到的 bbox 与记录**逐位一致**。

**三次尝试与实测结果（均已回滚）**：

| 尝试 | 做法 | 实测 | 结论 |
|---|---|---|---|
| A 周向窗口周期归一化 | 把 uv 窗口平移进曲面周期，避免 OCCT 在周期处**截断**窗口（否则 1.57 的窗口被截成发丝片） | SM4 161→125、sm2 1861→1794，14 个面重建失败 | 回滚：在本数据集上净负 |
| B 采样 bbox（面 UV 网格 7×7/9×9 + 顶点） | 用采样值替代 Bnd_Box 作为窗口判据 | sm2 1861→1842（环面切分 18→6）但 SM4 161→150，导入 8.4→16.1 s（超 15 s 预算） | 回滚：收益不抵代价 |
| C 容差式窗口接受（containment 6% + 覆盖 75%） | 用“在框内 + 覆盖足够”替代纯距离判据 | 与基线相同（1861/161） | 回滚：未解决选择问题 |
| D 采样 bbox 只作**兜底救援**（快判失败且 gap ≤12% 时才算采样） | 把 B 的代价限制在几十个面上 | 首版 sm2 1861→1846（环面切分 18→6）但 SM4 161→150；收紧后 SM4 恢复 161、sm2 仍 1861，导入 8.65→**10.75 s** | 回滚：**无保真收益、白付 2 s** |

**保留的诊断资产**：`_face_uv_samples()`（面 UV 采样，代码内说明 Bnd_Box 的 4.1% 膨胀与 2× 导入代价）、
`_shape_bbox()` 文档注明该膨胀、`_window_ok()`/`_normalize_window()` 作为**已测过的两条路线**留档（当前不在调用链上，P54 维护轮决定去留）。

**R9 的更优路线（已写进规划）**：不要靠 bbox 距离判窗口——直接从**边界曲线**定窗口（环上椭圆/直线边的参数区间或端点投影），
或对 torus 走“环向解析窗口（圆 ∩ 投影凸包，P45 已有）+ 管向量由边定”，避免整圈建面后再裁剪。
