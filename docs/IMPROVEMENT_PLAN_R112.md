## E. 口径（R112 起沿用）

1. **`dimN` 绑定约束序号**，且只有 `dist`/`radius` 行有值；拒绝信息必须点名「越界」或「不是尺寸」，
   并列出**可引用的序号**（R111 纪律 1）。
2. **链上任何位置的循环都算循环**：把「因循环而缺席的名字」报成循环，并在下发求解**之前**拦下（原子）。
3. **无法解析的尺寸行不得从树里消失**：序号是唯一的修复入口（纪律 91）。
4. **测量只读**（纪律 85）：`dof_report` 在副本上求解，测量不得改变工作负载。
5. **多闭环草图 = 一环一体**（R107 口径）：多闭环体积断言必须**求和**，不能只量 `bodies[0]`。
6. **尺寸单位三分**（R110 口径）：约束里**数值**是米、**表达式/`dimN`** 是毫米、**API/UI 传入**是毫米；
   换算只在 `dimensions()` 与 `_solver_rows()` 两处发生。
7. 每轮结束照旧：定向 + 定向回归批 + 全量回归 + 快照 `--check`（两种解释器）+ 同轮文档 + 提交推送。
