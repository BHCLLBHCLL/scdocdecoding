## 3. 边界（转 R114）

1. **镜像轴靠「最近一次点击」**，不是持久的选择集：没有高亮、不能框选多条；放弃拾取则退回草图轴。
2. **圆周阵列只有一个圆心 + 总角度**：没有「沿曲线阵列」「阵列方向拾取」「跳过实例」。
3. **跨草图引用按下标（`S2_dim5`）**：不支持按草图名引用（草图可改名，序号不变）；被引用草图**删除**后该表达式变成「未知参数」。
4. **拉之前不重解表达式尺寸**（R111 口径沿用，R113 仍是「按草图所画」拉伸）。
5. **删闭环不删体**（R112 边界沿用）：闭环删掉后其体仍在文档里。
6. **A-3 尺寸驱动预览、A-7 冲突高亮到视口**仍顺延；装配线仍在等 **B-1 装配层级/局部坐标系**。

## 4. 口径与纪律（R113 新增）

1. **引用名要能被发现**：命令能从几何/数据里取到的东西（草图序号、尺寸序号），UI 必须在同一处写出来
   （树的提示给出 `dimN` 与 `S1_dimN` 两种写法），否则等于没实现（纪律 91）。
2. **命名空间按需展开**：跨草图引用只拉「被点名的」草图；但**候选表达式**里点名的也算——
   否则第一次驱动跨图引用时命名空间里还没有它（本轮踩过：`set_dimension` 先解析候选文本，再落盘）。
3. **循环点名要有入口视角**：入口草图用 `#N`（沿用 R111 格式），其它草图用 `S1#N`，
   这样「我刚改的那条 → 谁指回来」一眼可读。
4. **拾取半径沿用捕捉半径**（不再新写常数）：`nearest_segment` 的容差来自 `sel.snap_radius_mm`，
   与 R112 的「一个概念一个数」一致。
5. **模型里有的东西树里必须看得到**：只有草图没有实体时也要列出草图（本轮修）。
