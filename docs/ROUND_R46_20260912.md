## 关键构造（可复用的测试范式）

要造一个**厚度均匀的斜面件**，最省事的办法是“**斜向拉伸**”：

```python
prof = face_from_polygon(平面内 4 点，法向 n = (1,0,1)/sqrt2)
sheet = prism(prof, vec=(0.01, 0.01, 0))     # 斜向拉伸 → 平行六面体
thick = |vec · n|                            # 沿法向的板厚（均匀）
```

平行六面体的两个端面法向都是 ±n 且**沿 n 的厚度恒定**——这正是让闭式可测的前提
（若用“棱柱+斜切”构造楔形件，板厚随位置变化，闭式就不可判）。
