# R90 轮次交付记录（2026-09-12）

> 规则：每完成一轮改进即重新基线并产出**下一编号**的规划。本轮（R90）执行 P422：**尺寸链第三批**。
> 交付：一条链**两种叠加口径的并列标注**（±极值 / ±统计）+ **链线图形化**（注记层引线），
> 文字仍只有一处实现（`drawing.dim_text`），因此画布/SVG/DXF 三处必然一致。

## 1. 做法

| 对象 | 内容 |
|---|---|
| 极值标注 | `chain_dimension(..., mode="worst")`：`tol = Σ\|tol_i\|` |
| 统计标注 | `chain_dimension(..., mode="rss")`：`tol = √(Σtol_i²)` |
| 并列 | 两条标注**共用链和**，只差 `tol`；`offset` 相差 `gap_mm`（默认 8mm），互不压字 |
| 链线 | `annotation.Leader`（anchor=链首、elbow=链尾、arrow=none、layer=NOTE）：注记层对象，**不属于几何** |
| 文字 | `dim_text(标注)` 单点渲染 → `10.0 ±0.6` / `60.0 ±0.374` |

接口：`dimchain.chain_annotations(dims, tol_gap, gap_mm, modes)` 返回
`{worst, rss, line, texts, span_mm, count}`；链不成立时抛 `ValueError` 并带上断口数与方向违规数（沿用 R69 口径）。
GUI：`SheetCanvas.add_chain_labels()` 一次推入两条标注 + 链线，并走既有 undo（`undo.push(state)`）。

## 2. 验收（每条都可复算）

| 检查 | 期望 | 实测 |
|---|---|---|
| 两口径公差 | `0.1+0.2+0.3 = 0.6`；`√(0.01+0.04+0.09) = 0.374` | ✅ rel 1e-12 |
| 链和一致 | 两条都是 60.0 mm | ✅ |
| 文字不同且各带自己的公差 | `60.0 ±0.6` / `60.0 ±0.374` | ✅ |
| 并列不重叠 | offset 差 = 8 mm | ✅ rel 1e-12 |
| 链线是注记 | `annotation_layer == "NOTE"`；几何为 4 元组且 style.layer=NOTE | ✅ |
| 链线跨度 | x 从链首 0 到链尾 60mm（含尾段），且整体在链上方 | ✅ |
| 不碰几何 | 标注前后实体**体积与包围盒逐分量不变**（标注函数根本不接收 shape） | ✅ 1e-12 |
| 断链 | 10mm 断口 → `ValueError`（带断口数） | ✅ |
| 口径数量 | `modes` 必须两个，否则报错 | ✅ |
