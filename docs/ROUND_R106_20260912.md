## 3. 设计要点（写进 R107 口径）

1. **曲线随特征走，`sketch_id` 只做活链接**：这样"草图被删"不会破坏重放（定义还在），只影响同步；反过来，从旧版本文件读到的特征（没有 sketch_id）也能重放。
2. **同步是提交式的**：先构造新定义 → 重放成功才写入特征参数；失败则回滚参数并报告（沿用 `edit_feature` 的原子语义，纪律 87 的标尺思想）。
3. **兜底路径不记特征**：`extrude_active` 的圆→圆柱兜底会产出**多个**实体，一个 `sketch` 特征表达不了，因此不记（宁可没有历史，也不给假承诺）。

## 4. 边界（转 R107 候选）

1. **多轮廓分区拉伸**：一张草图多个闭环 → 目前只按整体外轮廓拉伸（`sketch_outline` 取一个闭环）；分区（每环一个体）未做。
2. **圆/样条截面仍是多边形近似**（0.16% 量级，R105 遗留 B-2）。
3. **尺寸标注驱动草图**：`con.dim` 的解算结果写回曲线 ✓，但"改标注值 → 改草图尺寸"还不能反向驱动（新候选）。
4. **拉伸选项**：只用到距离；反向/两侧/到面未接入 `sketch` 特征。
5. **模式切换不进撤销栈**（R105 遗留 B-3）。
