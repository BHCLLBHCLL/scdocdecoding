## 3. 边界（转 R120）

1. **改指向只到「另一张草图的同序号/指定序号」**：不支持改到参数表、不支持跨文档、不支持一次改一批。
2. **预览只是一次性的列表**：没有逐条勾选/取消（要么全修，要么只修选中的那一条）。
3. **定位只看「还在的成员」**：不显示已删成员原来的位置（没有历史位置信息）。
4. **导入组（`imported=True`）也参与体检**：官方文档带来的分组只读，目前与其他组一视同仁。
5. **A-4 尺寸驱动预览、A-5 拉前重解、A-6 锚点可控、A-7 三维模式选草图** 仍顺延；装配线仍在等 **B-1**。

## 4. 口径与纪律（R119 新增）

1. **修复要保留意图**：能改指向就不要冻结、能冻结就不要删（本轮把三者按「保留程度」排列）。
2. **破坏性动作先说后做**：一键修必须先能给出「将做什么」的清单，且清单来自**同一份**告警数据。
3. **作用域要收到具体条目**：按名字定位时必须在**该条目**内找（否则同名/导入条目会串味——本轮实测导入组串味）。
4. **拒绝对每种参数组合都要有话说**：目标不存在、目标没这条尺寸、没给目标，分别是三句话。
