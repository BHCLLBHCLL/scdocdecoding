# R56 轮次交付记录（2026-09-12）

> 规则：每完成一轮改进即重新基线并产出**下一编号**的规划。本轮（R56）执行 P303：**钣金接缝 junction**。
> 交付：三种接缝几何（释放三角 / 接缝矩形 / 连接搭接）+ 五项验收 + 八层接线；两条实测教训（面心≠角点、贴边布尔退化）。

## 1. 内核 `K.junction(solid, face, size, mode, width)`

| 模式 | 几何 | 闭式 |
|---|---|---|
| `release` | 面角处去掉**直角三角形**（两直角边 `size`） | 去除量 `= size²/2 × t` |
| `seam` | 去掉**矩形** `size × width` | 去除量 `= size × width × t` |
| `connect` | 面上补**矩形搭接片** `size × width` | 加料量 `= size × width × t` |

`t` 沿面法向从实体包围盒量出（同百叶/敲落）；切割刀跨越两面各留 1 µm，保证贯穿。
放置：**面的 (u_min, v_min) 角**（两折弯相交处），差集包围盒即为闭式足迹。

## 2. 两条实测教训（都是断言抓出来的）

1. **面心 ≠ 角点**：第一版把三角形开在 `base` —— `_face_uv` 返回的 base 是**面心**，
   差集包围盒实测 `[0.010, 0.014]` 而不是 `[0, 0.004]`，放置断言当场暴露。
   修复：`at(du, dv)` 先减去 `lo_u − base·u` / `lo_v − base·v` 再放样。
2. **贴到对边会退化**：`size` 恰等于面跨度时，刀面与实体对边**共面**，
   布尔只切掉一半（实测 `0.02` 三角 → `2.0e-7` 而不是 `4.0e-7 m³`）。
   修复：边界改为**严格不等式**（`size < 面跨度 − 1e-9`）并显式报错，
   把"贴边"从静默错误变成可判定的非法输入（与 `corner_relief` 的靠边内缩同一类问题）。
