## 1. 网格与指标 `scdm/mesh.py`

| 项 | 闭式 / 判据 |
|---|---|
| 三角化 | OCCT 分面后**焊接**（按容差网格合并顶点）：立方体因此是 **12 三角形 / 8 顶点**（不焊接会是 24 个顶点——每面一份拷贝） |
| 面积 | 三角形面积和 vs `K.area`：**相对差就是离散误差**，显式报出而不是藏在松容差里（立方体 rel = 0；r=10 mm 圆柱 1e-5 弦差 → rel 2.9e-4） |

| 报告 | `quality_report()` + `write_report(json|csv)` + `read_report()`（JSON 逐字段往返） |
| 派生件纪律（77） | 网格只存在会话里（`kdoc.meshes`），**不入 .scdm**（测试直接检查清单里没有 meshes 段）；出会话的是**报告** |

## 2. 两条实测教训

1. **OCCT 增量网格只细不粗**：`BRepMesh_IncrementalMesh` 不会把已有三角化变粗——同一实体先用细弦差网格化，再用粗弦差请求会**原样返回旧网格**（实测两次统计逐位相同）。
   修法：`mesh_shape` 先 `BRepTools.Clean` 再网格化，保证"请求的弦差就是真的弦差"。
2. **角度判据会压过弦差**：角度容差 0.5 rad 在该圆上已给出 ~13 段（矢高 ≈ 2.9e-4 m），所以比它更粗的弦差（0.0005、0.005）**完全不起作用**（都是 100 三角形）；
   测试因此把粗细对设在 `1e-3 ↔ 1e-5` 两侧，并把这个"弦差何时才起作用"的门槛写进断言注释。
