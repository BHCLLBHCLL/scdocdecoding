## E. 口径（R113 起沿用）

1. **焊接 ≠ 捕捉**（R112）：捕捉半径是绘图辅助（视口 5mm），焊接容差是修复量（文档级、默认 0.1mm）；
   共用一个数会把相距 2mm 的轮廓并成一个（实测）。
2. **局部化与计数同源**（R112）：`len(dependent) == rows − rank` 构造性成立。
3. **测量只报「开着的」缝**（R112）：忽略已重合点对。
4. **再拉一次不复制已建体**（R112）：同一草图二次拉伸按 loop 原地更新旧体。
5. **拒绝要能照做**（R112）：闭环缺失时同时给出缝的大小与当前容差。
6. **`dimN` 绑定约束序号**（R111），只有 `dist`/`radius` 行有值；拒绝信息必须列出可引用序号。
7. **测量只读**（纪律 85）：`dof_report` 在副本上求解。
8. **多闭环草图 = 一环一体**（R107）：多闭环体积断言必须**求和**，不能只量 `bodies[0]`。
9. **尺寸单位三分**（R110）：约束里数值是米、表达式与 `dimN` 是毫米、API/UI 传入是毫米；
   换算只在 `dimensions()` 与 `_solver_rows()` 两处。
10. 每轮结束照旧：定向 + 定向回归批 + 全量回归 + 快照 `--check`（两种解释器）+ 同轮文档 + 提交推送。
