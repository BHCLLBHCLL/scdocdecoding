## E. 口径（R119 起沿用）

1. **诊断的下一步是修复**（R118）：报告要带能执行的动作，并说明别的动作为什么不行。
2. **删除按值不按下标**（R118）：批量操作时下标会移位。
3. **冻结 = 把当前几何写成数**（R118）：不猜、不取零，冻结前后几何不变。
4. **连线与标记同一口径**（R118）：只有 `state=redundant` 才连线。
5. **诊断指到「哪一条」**（R117）；**体检常驻结构树**（R117）；**破坏性动作给选择**（R117）；
   **Qt 对象必须有活着的 QApplication**（R117）。
6. **标记能说话 / 体检覆盖所有按 ID 指向的结构 / 选择顺序是用户意图 / 不连续就拒绝**（R116）。
7. **诊断落在几何上 / 一行坏数据不许让整张报告失效 / 模式的真相在会话 / 文件类型看内容 /
   删要有据可回退**（R115）。
8. **画出来的和能选中的是同一份几何 / 拾取偏好可预期 / 按折线走就按折线说 /
   失败指到具体对象且仍列可引用名**（R113/R114）。
9. **一个概念一个数 / 局部化与计数同源 / 测量只读 / 多闭环体积断言求和 /
   再拉一次不复制已建体**（R107/R112/纪律 85）。
10. **尺寸单位三分**（R110）：约束里数值是米、表达式与 `dimN` 是毫米、API/UI 传入是毫米。
11. 每轮结束照旧：定向 + 定向回归批 + 全量回归 + 快照 `--check`（两种解释器）+ 同轮文档 + 提交推送。
