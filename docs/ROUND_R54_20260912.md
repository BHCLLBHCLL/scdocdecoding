# R54 轮次交付记录（2026-09-12）

> 规则：每完成一轮改进即重新基线并产出**下一编号**的规划。本轮（R54）执行 P295：**钣金补项——角撑 gusset / 舌片 tab**。
> 交付：两项面级**加料**成形（角撑三角形板、舌片矩形凸出）+ 五项验收 + 八层接线；本轮没有新表格，只有两条闭式与一条"同面重叠"的实测教训。

## 1. 内核（`scdm/kernel.py`）

| 项 | 实现 |
|---|---|
| 角撑 `gusset(solid, face, length, height, thickness)` | 三角形在 `(u, n)` 平面内：`length` 沿面、`height` 垂直面，沿 `v` 拉伸 `thickness`；底边**落在面平面内**，因此 fuse 是面接触（不像敲落筋那样只是点接） |
| 舌片 `tab(solid, face, length, width, height)` | 面上 `length×width` 的矩形凸出 `height`（盒体 fuse 到面） |
| 闭式 | 角撑 `= length×height/2×thickness`；舌片 `= length×width×height`（两者都是精确棱柱，实测 rel ≤ 5e-15） |
| 面框架 | 新增 `_face_uv`（把 louver/knockout 内联的 u/v 配方收敛成一处）与 `_face_span`（面在本帧内的跨度） |
| 非法 | 非正尺寸；**超出面**（角撑长度/厚度、舌片长度/宽度 > 面跨度）——用面顶点在 u/v 上的投影跨度判定 |
| 加法语义 | 两者都是**加料**（fuse），因此不断开连通性：体数=壳数=1，几何有效（无开放壳/自交/短边） |

## 2. 同面重叠（本轮实测教训）

GUI 用例先在**同一面**上做角撑再做舌片，体积只增加了 `1.0833e-8` 而不是 `1.5e-8`：
两者在面中心**重叠**，舌片把角撑的一部分包进去了（重叠量 `4.1667e-9``m³` = 三角形被矩形footprint截下的那一块）。
这不是实现 bug，而是"加料"类特征的语义：闭式只在**互不重叠的放置**下可加。
测试因此把舌片放到**对面**（底面）再断言；纪律 71 由这条写成。
