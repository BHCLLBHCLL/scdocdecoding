## E. 口径（R123 起沿用）

1. **界面要追上库层**（R122）：库层有的参数，界面要么暴露要么明确记为边界。
2. **默认值就是历史行为**（R122）：新参数不得悄悄改变旧语义。
3. **GL 内容要单独取**（R122）：窗口截图抓不到 GL 表面，必须从渲染窗口取像素再合成。
4. **工具要能离屏自检**（R122）：不依赖显示器的测试。
5. **挑选要有两个方向**（R121）；**目标从界面里点**（R121）；**锚点显式化**（R121）；**前提错了要更正**（R121）。
6. **批量操作要能挑 / 只读就是只读 / 动作与目标都可按范围给 / 两条路径合一**（R120）。
7. **修复要保留意图（改指向 > 冻结 > 删除）/ 破坏性动作先说后做 / 作用域收到具体条目**（R119）。
8. **诊断的下一步是修复 / 删除按值不按下标 / 冻结 = 把当前几何写成数**（R118）。
9. **诊断指到「哪一条」/ 体检常驻结构树 / 破坏性动作给选择 / Qt 对象必须有活着的 QApplication**（R117）。
10. **标记能说话 / 体检覆盖所有按 ID 指向的结构 / 选择顺序是用户意图 / 不连续就拒绝**（R116）。
11. **诊断落在几何上 / 一行坏数据不许让整张报告失效 / 模式的真相在会话 / 文件类型看内容**（R115）；
    **画出来的和能选中的是同一份几何 / 拾取偏好可预期**（R114）。
12. **一个概念一个数 / 局部化与计数同源 / 测量只读 / 多闭环体积断言求和 /
    再拉一次不复制已建体 / 尺寸单位三分**（R107–R112）。
13. 每轮结束照旧：定向 + 定向回归批 + 全量回归 + 快照 `--check`（两种解释器）+ 同轮文档 + 提交推送。
