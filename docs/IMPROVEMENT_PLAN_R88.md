## 2. R88 工作项：P415 装配爆炸图第二批

现状：爆炸图第一批只有"按比例外扩"。第二批要求：

- **方向**：`axis`（沿指定轴）/ `radial`（自装配中心径向）/ `scale`（沿用第一批的等比外扩）；
- **可数**：每个组件返回**位移向量**（爆炸前后位置差），总位移可累加；
- **可还原**：`explode=0` 或撤销即回到原位（位移全部为零向量）；
- **八层接线**：kernel 层提供位移计算 → `scdm/assembly.py`（或既有装配模块）承载 → op `asm.explode` → 目录/live → GUI `_do_asm_explode` → 回放测试 → 视口（移动装配体，不改几何）。

**验收**：位移向量可数（每体一组，单位与模型一致）、等比/沿轴/径向三种模式的**位移方向**与**模长**可复算（如沿轴模式位移 = 距离 × 步进系数）；
撤销后所有位移为 0；命令测试 + 回放测试就位；快照计数同步。**成本**：1 天。
