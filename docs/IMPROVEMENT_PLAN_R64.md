## 2. R64 工作项（P335–P338）

### P335 · 贴体体网格首批（最高优先，R62/R63 顺延）

- **动作**：边界格用 `K.common(体素盒, 实体)` 裁剪后再四面体化（或用裁剪体积直接计），
  使体积误差随格距**二阶**收敛；沿用 P327 的闭式对拍与门槛清单。
- **验收**：同球同格距下误差比体素版低一个量级（可数对比）+ 退化 0 + 回放一致 + 非法（空裁剪）。**成本**：1.5 天。

### P336 · 焊接符号元数据面板（`weld.symbol` 占位转 live）

- **动作**：符号挂到焊件组元的成员（已有 `WeldSymbol` 模型）——GUI 面板：选成员 → 类型/尺寸/长度/间距 →
  写入 `Weldment.symbols` → 状态栏/树节点显示；`.scdm` 往返；导出（BOM/清单带符号）。
- **验收**：符号往返一致 + 指向不存在成员报错 + 面板路径可测 + 占位从 3 降到 2。**成本**：1 天。

### P337 · 可选补测（内存/帧率）｜P338 · 每轮维护（必做）

- P337 沿用 `tests/test_perf_budget.py` 口径；P338 快照/CI/口径同步 + 编号递增 + 轮次记录同轮补齐（纪律 65）。
