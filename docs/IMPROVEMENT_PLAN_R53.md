## 2. R53 工作项（P291–P294）

### P291 · 梁第二层：沿折线 + 焊件组元（最高优先，R52/P288 顺延）

- **动作**：`beam_polyline(profile, points, ...)` 沿折线逐段生成并用**段长闭式**复算（体积 = Σ A×段长；
  转折处补角或留缝需显式说明）；焊件组元（父梁 + 子梁，共享截面/材料，增删子梁后父梁不变）；
  焊接符号**元数据模型**（符号类型/尺寸/位置，`.scdm` 往返），面板占位 `weld.symbol` 升级为 live 或继续占位（写明理由）。
- **验收**：折线梁体积闭式（1e-9）+ 组元随动 + 符号元数据往返一致 + 非法（重合点/单点折线）。**成本**：1.5 天。

### P292 · 钣金补项：角撑 gusset / 舌片 tab

- **动作**：面级成形两项（沿用 louver/knockout 的面框架 + prism/cut 路径），角撑=折角处三角加料，舌片=局部凸出；
- **验收**：闭式（面积/体积）+ 非法 + 极端 + 回放 + **展开兼容（纪律 60/67：数值等价，不只是不抛）**。**成本**：1 天。

### P293 · 可选补测（内存/帧率）

- **动作**：沿用 `tests/test_perf_budget.py` 口径补内存峰值与帧率基线。**成本**：0.5 天（可选）。

### P294 · 每轮维护（必做）

- 快照/CI/口径同步（`tools/gen_devplan_snapshot.py --update`）；编号递增；轮次记录与规划同轮补齐（纪律 65）。
