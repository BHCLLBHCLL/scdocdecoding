## 3. 边界（转 R124）

1. **算式目标只在库层/脚本**：GUI 的改指向仍只给「草图序号」；参数与算式目标需要脚本或后续选项页。
2. **锚点标记不随实例移动**：标记画在**用户选的锚点**上；副本各自的锚点位置只在状态/几何断言里可见（未逐个画标记）。
3. **参考图会过期**：GUI 布局改动后必须重新生成并提交（README 里写了命令，但没有自动校验图是否过期）。
4. **截图仍要原生平台才有 3D**：离屏跑只有控件（`3d=False`）。
5. **A-1（R123 计划里的）预览清单可勾选、A-3 交互式预览、A-4 尺寸驱动预览、A-5 拉前重解、A-6 三维模式选草图** 仍顺延；装配线仍在等 **B-1**。

## 4. 口径与纪律（R123 新增）

1. **数字要能看见**：锚点是个数时，界面必须把它画出来；否则「哪个点跟着走」只能靠猜。
2. **标记与状态条同源**：只有用户*选定*的锚点才标记，默认值不标 —— 两处说法永远一致（纪律 84/91）。
3. **陈旧标记要清**：标记属于「上一次操作」，选择一变就清，避免指着一个不再成立的对象。
4. **文档图要能重生成**：界面参考图连同生成命令一起入库，让「图过期」成为可修的问题，而不是无声的谎言。
5. **退化消息要修**：自引用原本报「未知参数」，属于把「循环」说成「笔误」——拒绝信息必须指向真正的原因（纪律 86）。
