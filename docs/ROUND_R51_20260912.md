> 规则：每完成一轮改进即重新基线并产出**下一编号**的规划。本轮（R51）执行 P283：**梁/焊件首批**。

## 1. 内核 `scdm/beams.py`（P283）

| 项 | 实现 |
|---|---|
| 6 种轮廓 | 扁钢 `b×h` / 圆钢 `Ød` / 圆管 `Ød×t` / 工字钢 `h×b×tw×tf` / T 型钢 / 不等肢角钢 `a×b×t` |
| 造形 | 多边形轮廓 = 精确平面多边形 `face_from_polygon` + `prism`；圆截面 = 精确圆柱（圆管 = 外圆柱 − 内圆柱，**只有内刀超长**，管长因此精确） |
| 闭式 | 面积 + 形心 + 绕形心二阶矩（T/角钢用平行轴定理），`j = ix + iy` |
| 校验 | 参数必须为正/齐全、圆管 `2t < d`、工字钢 `2tf < h` 且 `tw < b`、T 型钢 `tf < h`、角钢 `t < min(a,b)`、长度 > 0、轴向非零 |
| 任意轴 | `beam(..., axis=...)` 与 `beam_along(p0, p1)`：截面随线段方向、形心落在线段中点 |
| 内核支撑 | 新增 `K.section_props(face)`（面积/形心/ix/iy/j）与 `K.inertia(solid)`（绕形心二阶矩矩阵）——把“闭式”变成可判定的量（纪律 66 的同类做法） |

**复算结果**（测试同款）：6 种轮廓 `A/ix/iy` 与 `K.section_props` 相对误差 ≤ 8e-14（多为 1e-16）；
`体积 = A×L`、`ixx = L·ix + A·L³/12`、`izz = L·(ix+iy)` 全部 ≤ 1e-15。

## 2. 同轮修掉的两个实测缺陷（都是“不跑复算就看不出来”）

1. **圆管截面面方向**：给环形面加内孔线时，内孔线必须与外线**反向**；同向时 OCCT 生成自交面，
   实测面积 **0.005118 m² = 环面积的 9.5 倍**（应为 0.000537 m²）。修复：`Add(inner.Reversed())`。
2. **圆管长度**：外刀与内刀都超长会让管子长 2 µm（体积偏 **+1e-5**）；改为只让内刀超长，管长精确、
   闭式回到 1e-15。
