## 3. 边界（转 R121）

1. **选中即执行**：「只修选中的」没有二次确认（靠撤销）；预览仍是「将要做什么」的一次性清单，不能逐条勾掉。
2. **只读只覆盖命名选择/组**：导入组件上的**配合**目前仍可被删除（组件没有 imported 标记）。
3. **改指向目标用草图序号**：GUI 只能填 `S<序号>`，没有草图下拉；也不支持改到参数表。
4. **`repair_selected` 按告警 id 匹配**：如果两条告警的 id 相同（同名条目同 id），会一起修。
5. **A-4 尺寸驱动预览、A-5 拉前重解、A-6 锚点可控、A-7 三维模式选草图** 仍顺延；装配线仍在等 **B-1**。

## 4. 口径与纪律（R120 新增）

1. **批量操作要能挑**：默认「全部」可以，但必须能把范围缩到用户选中的那几条，且未选中的**逐项不变**。
2. **只读就是只读**：来自导入结构的东西，体检要报、修复要拒、计划要说「跳过」，绝不在原结构上删改。
3. **动作可以按范围给**：`{scope: 动作}` 映射让「尺寸改指向、其余删除」一次说清楚；目标也可以按行给。
4. **两条代码路径要合一**：`repair_all` 直接委托 `repair_selected`，避免「全部」与「选中」行为分叉。
