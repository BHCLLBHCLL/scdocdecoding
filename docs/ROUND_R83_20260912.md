## 1. 内核：一处实现，三处使用

| 函数 | 作用 |
|---|---|
| `K.watertight_report(shape)` | 四元组 `free_edges / open_edges / seam_edges / free_loops`（与 `tools/free_edge_report.py` 同源） |
| `K.open_edge_points(shape, limit)` | 最多 limit 条缺口边的**中点**（模型单位，直接可落到标记上） |
| `K.watertight_text(rep)` | 中文一行：`封闭 ✓` / `未封闭 4 处（自由环 1）` / 带缝边时 `（自由环 1，缝边 2）` |

## 3. 验收（可数）

| 用例 | 实测 |
|---|---|
| 封闭立方体 | `{free 0, open 0, seam 0, loops 0}`、文案 `封闭 ✓` |
| 去掉一个面的盒子（开壳） | `free 4, open 4, loops 1`、文案 `未封闭 4 处（自由环 1）` |
| 整圈柱面片 | `open 2`（两条边缘圈）、`seam 0`（缝边被同一面用两次，本就计数为 2） |
| `open_edge_points` | 4 个点全部落在盒内；`limit=2` 时返回 2 个 |
| `repair.check` op | 消息含 `未封闭 N 处`，且 N 与 `K.watertight_report` 独立复算一致 |
| 回放 | `replay([{cmd: repair.check}], doc)` 返回 `OK repair.check` |
