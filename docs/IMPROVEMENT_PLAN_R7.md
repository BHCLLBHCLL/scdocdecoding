理由：P45 先消灭**错位几何**（正确性红线），P46 才能把保真度推到 ±0 并开门禁；P47–P50 是积压

## 5. 纪律（延续 + R7）

1. 无官方哨兵不宣称"官方可开"；无逐字段 diff 不宣称"官方对齐"。
2. 解析/导入成功率必须写清口径路径（tokenizer ≠ 文档加载 ≠ B-rep 导入）。
3. OCCT 几何算子的功能测试必须含非法/极端参数。
4. 重写文件前核对 `totalLines`。
5. 解析器宽松化须配"合成流常量扫描 + 官方样本计数对拍"。
6. 官方数据功能的验收必须给逐项计数表。
7. 性能改动先 profile。
8. 兜底/降级默认关闭 + 留痕。
9. **新增**：解码器不得依赖固定 token 下标（官方同版本存在布局变体），必须按**角色位次/种类**；
   新增布局变体时先补"合成流"单测。
10. **新增**：导入类功能的验收必须同时给**数量**与**几何位置**（bbox）两个判据。
11. **新增**：同一几何量若存在两个独立来源（曲线参数 / 顶点表），必须**交叉校验**，
    冲突时以**点表**为准并留痕；单来源规则在官方数据上的冲突率实测可达 77%（104 条中 80 条）。
12. **新增**：包围盒判据要分层——**面**级用面自身 bbox（严），**模型**级只用 point 表的
    bbox 做"离谱几何"兜底（宽），且**退化轴跳过**（自研写盘只存 2 个缝合顶点，柱面模型 bbox 是一条线）。
