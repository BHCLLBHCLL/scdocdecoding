## P29：修复清单（每一类都有实测支撑）

1. **`e(None)` 崩溃**：可选指针在官方流中普遍缺失，`self.e(None)` 直接 `TypeError` → 全模型
   导入中断。已改为 None-safe。
2. **`edge_endpoints` 只认曲线参数**：官方 straight 记录**省略 t0/t1**，导致环无法重建、面被整片丢弃。
   现按 曲线参数 → **边顶点 v1/v2** → 边 pstart/pend 三级回退。
3. **`face_from_polygon` 对重复点敏感**：官方环重复顶点使 `MakePolygon::Close` 抛
   `StdFail_NotDone`；现去重 + 至少 3 点校验。
4. **单面失败拖垮整个部件**：`_rebuild_face`/`face_loops_polygons` 的异常未隔离；现逐面捕获。
5. **缝合只留第一个叶片**：`sew_faces` 取 `solids[0]`/`shells[0]`，SampleModel1 的 8 壳/103 面
   被压成 4 面。新增 `sew_bodies`：保留全部叶片，且**任何实体化转换必须不比缝合结果少面**。
6. **body→shell→face 链不完整**：samplemodel3 只链到 12/111 面 → 单体模型直接以"全部面"为准；
   壳/环/协边三级补"指针反查"。
7. **网格兜底全文档跑**：默认只在"完全没重建出体"时触发，并写 `import_warnings`。

- **SampleModel4**：34 个 B 样条面 + 5 个环面面未被重建（`no-poly surf=spline/torus`）。

- **性能问题必须先 profile 再改**：samplemodel2 的 50 s 起初被归因于"面多"，profile 显示
  3.3 s 在部件重建、**47.8 s 在一处全文档网格兜底**——不 profile 就会优化错对象。
