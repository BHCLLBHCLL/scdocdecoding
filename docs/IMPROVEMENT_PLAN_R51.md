## 2. R51 工作项（P283–P286）

### P283 · 梁/焊件首批（最高优先，R8/P53 起顺延至今）

- **动作**：6 种梁轮廓（L 角钢 / T / I 工字 / 圆管 / 圆钢 / 扁钢）+ 沿草图或边生成；
  截面惯性矩闭式（`I` 与体积、包围盒）；焊接符号占位 + `.scdm` 数据模型承载梁规格（截面/材料/朝向）。
- **验收**：闭式（体积 + 惯性矩）+ 非法（负尺寸/壁厚吃掉截面）+ 极端（最小可制造截面）+ 回放 + 视口标记五条对齐既有特征族。
- **成本**：1.5 天。

### P284 · 图面尺寸第二批（多选/吸附/undo）

- **动作**：尺寸多选、拖动吸附（端点/中点/交点）、undo/redo 入 `scdm.history`。
- **验收**：吸附命中闭式（坐标对齐到 1e-9）+ 三条 undo/redo 往返一致性。**成本**：1 天。

### P285 · 可选补测（内存/帧率）

- **动作**：打开大装配的内存峰值与帧率基线（沿用 `tests/test_perf_budget.py` 口径）。
- **验收**：< 20 s 可交互 + 帧率 ≥ 基线。**成本**：0.5 天（可选）。

### P286 · 每轮维护（必做）

- 快照/CI/口径同步（`tools/gen_devplan_snapshot.py --update`）；编号递增；
  关键功能完成即提交推送；轮次记录与规划**同轮补齐**（纪律 65）。

## 4. 纪律（延续 + R51 新增）

1–66 条延续。

67. **新增**：下游兼容（展开/分析）的断言必须是**数值等价**——与未成形件对照**同一条数值**
    （展开长、折弯数、链序），"不抛异常"不算通过。R50 的敲落正是靠这条抓出
    `detect_bends` 把敲落片壁误判成第二条折弯、展开长**静默偏大 9%** 的缺陷；
    若只断言"不抛"，该缺陷会带着错误展开长进入后续所有轮次。
