## 3. 定位（未修，转 R130）

1. **P-1 体积（80 例）根因已定位**：体积是**按面解析积分**求和的（`body_metrics → face_metrics['volume_contrib']`），带内环的面（孔、沉孔、切口）只按外环算——所以 `14_hole_cbore_001_M6` 面/边都对（10 面）而体积仍是毛坯的 24000（应为 23108.84）；锥/球这种无平面体的更直接读 0（`01_primitives_cone_001` 体积 0 vs 2094.4，且 SpaceClaim 只算 1 条边而我们算 2 条 = 多算了接缝边）。
2. **P-2 多体（25+3 例）是口径差异，不是漏读**：`06_pattern_linear_001_cyl_1d_5x10` 的文件里（文档层与 SAB 都）只有 **1 个体** `Pattern_Pin`，SpaceClaim 读回 **5 个**同名体（每个 62.8mm³）——它报的是**阵列求值后的实例**；矩阵/镜像同理。下一轮要决定：我们把实例展开，还是在语料对照里把这类标成「口径差异」并单列。
3. **P-4 仍是 2 例**：`15_mesh_stl_import_001`（edge table 计数越界）、`20_combo_mesh_032`（body terminator）。

## 4. 边界（转 R130）
