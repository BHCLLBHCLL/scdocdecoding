## 2. R65 工作项（P339–P342）

### P339 · 裁剪片真四面体化（最高优先，R64 顺延）

- **动作**：对边界裁剪片做真四面体分解（按面片三角化 + 体心扇：把裁剪实体的每个三角面片与内部点连成四面体；
  或体心 + 面片扇形分解），使贴体版的体积误差随格距**二阶**收敛；沿用 P327 的门槛清单与 P335 的对照。
- **验收**：同一球体误差随格距二阶下降（半格 → 误差约 1/4，可数对比）+ 裁剪片四面体数 = 面片数（可数）
  + 退化 0 + 回放一致 + 非法（不可三角化的裁剪片）。**成本**：1.5 天。

### P340 · 焊接符号元数据面板（`weld.symbol` 占位转 live）

- **动作**：把已有 `WeldSymbol` 模型接到面板：选焊件成员 → 类型/尺寸/长度/间距 → 写入 `Weldment.symbols` →
  树节点/状态栏显示；`.scdm` 往返；BOM/清单带符号；占位 3 → 2。
- **验收**：符号往返一致 + 指向不存在成员报错 + 面板路径可测 + 占位计数下降。**成本**：1 天。

### P341 · 可选补测（内存/帧率）｜P342 · 每轮维护（必做）

- P341 沿用 `tests/test_perf_budget.py` 口径；P342 快照/CI/口径同步 + 编号递增 + 轮次记录同轮补齐（纪律 65）。

## 4. 纪律（延续 + R65 新增）

1–80 条延续。

81. **新增**：离散判据的**粒度**必须与用量一致——"格心在内"只保证格心，要用整格体积就得验角点，
    要用部分体积就得裁剪。R64 实测：把"格心在内"的格整格保留又叠加裁剪，体积高了 12.7%；
    同类问题在采样、包围、判交里都会出现，先问"这个判据保证的到底是什么"。
