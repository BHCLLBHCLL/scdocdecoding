## E. 口径（R127 起沿用）

1. **预览不改文档**（R126）：预览在副本上算；取消是「什么都不做」，所以状态条敢说「取消即不变」。
2. **预览与提交同源**（R126）：预览用的建体代码就是重放用的那段（`features.sketch_solid`），不许另写一份。
3. **目标只有一套语法**（R126）：`S2` / `S2_dim5` / `param:d` / `expr:2*d` 都由库定义，界面只做快捷方式，不发明第二种写法。
4. **「空」也要判过期**（R126）：声称有 3D 视口就要有非背景像素，`ink=0` 直接 stale。
5. **破坏性动作先说后做**（R119/R126）：改尺寸先给预览与确认，取消不动文档。
6. **页面给的就是库收的 / 默认值必须仍是历史行为 / 工具要能自证 / 校验要能真的红**（R125）。
7. **画不出来就不算标记 / 校验不依赖平台 / 一个数只能有一个来源 / 谁说的算**（R124）。
8. **图要能重生成，也要能自证过期 / 数字要能看见 / 标记与状态条同源 / 陈旧标记要清 / 退化消息要修**（R123）。
9. **界面要追上库层 / 默认值就是历史行为 / GL 内容要单独取 / 工具要能离屏自检**（R122）。
10. **挑选要有两个方向 / 目标从界面里点 / 锚点显式化 / 前提错了要更正**（R121）。
11. **批量操作要能挑 / 只读就是只读 / 动作与目标都可按范围给 / 两条路径合一**（R120）。
12. **修复要保留意图 / 破坏性动作先说后做 / 作用域收到具体条目**（R119）。
13. **诊断的下一步是修复 / 删除按值不按下标 / 冻结 = 把当前几何写成数**（R118）。
14. **诊断指到「哪一条」/ 体检常驻结构树 / 破坏性动作给选择 / Qt 对象必须有活着的 QApplication**（R117）；
    **标记能说话 / 体检覆盖所有按 ID 指向的结构 / 选择顺序是用户意图 / 不连续就拒绝**（R116）；
    **诊断落在几何上 / 一行坏数据不许让整张报告失效 / 模式的真相在会话 / 文件类型看内容**（R115）；
    **画出来的和能选中的是同一份几何 / 拾取偏好可预期**（R114）。
15. **一个概念一个数 / 局部化与计数同源 / 测量只读 / 多闭环体积断言求和 /
    再拉一次不复制已建体 / 尺寸单位三分**（R107–R112）。
16. 每轮结束照旧：定向 + 定向回归批 + 全量回归 + 快照 `--check`（两种解释器）+ 同轮文档 + 提交推送。
