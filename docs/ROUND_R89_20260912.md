## 1. 闸门的真实成本（逐项计时，samplemodel2 环面片）

处置：把 `_trim_gates_ok` 改成**便宜判据优先、GProp 最后**——被前两道挡下的候选**一次 GProp 都不跑**。
这条顺序有回归测试（monkeypatch 计数：被包围盒拒绝的候选，`K.area` 调用数为 **0**；通过的候选恰好 **1** 次）。

## 2. 环面：为什么仍然拒绝

| 事实 | 实测 |
|---|---|
| 单次裁剪（线框 + pcurve + MakeFace + 修复候选 + 闸门） | **0.18 s/面** |
| 但环面有**两个候选曲面**（major/minor 与对调），失败的那个还要跑**仅环面使用**的采样窗口校验 | 合成 **0.54 s/面** |
| 36 个环面片 | **19.5 s**（导入 6.8 → 25 s） |
| 换来的收益 | 缺口 1002 → **990**（−12）、自由环 212 → **195** |

结论：**−12 条缺口换 +18 秒**，性价比不成立，环面继续走记录窗口路径；白名单保持`柱面 + 球面`。
R85 的"0.54 s/面"这次被拆开：**不是闸门贵，是"两个候选 + 采样兜底"贵**——这一条写进代码注释，免得下次又从头查。
