## E. 口径（R125 起沿用）

1. **画不出来就不算标记**（R124）：`在渲染器里` ≠ `在屏幕上`；点要有 cell 才成为图元。
2. **校验不依赖平台**（R124）：参考图比场景/模式条/体检数，不比像素（离屏与原生渲染本来就不同）。
3. **一个数只能有一个来源**（R124/84）：回归批的组成落盘成一个文件，文档与命令都引用它。
4. **谁说的算**（R124）：尺寸写的是什么，拉出来就得是什么；改口径时同轮更新锁口径的测试。
5. **图要能重生成，也要能自证过期**（R123/R124）。
6. **数字要能看见 / 标记与状态条同源 / 陈旧标记要清 / 退化消息要修**（R123）。
7. **界面要追上库层 / 默认值就是历史行为 / GL 内容要单独取 / 工具要能离屏自检**（R122）。
8. **挑选要有两个方向 / 目标从界面里点 / 锚点显式化 / 前提错了要更正**（R121）。
9. **批量操作要能挑 / 只读就是只读 / 动作与目标都可按范围给 / 两条路径合一**（R120）。
10. **修复要保留意图 / 破坏性动作先说后做 / 作用域收到具体条目**（R119）。
11. **诊断的下一步是修复 / 删除按值不按下标 / 冻结 = 把当前几何写成数**（R118）。
12. **诊断指到「哪一条」/ 体检常驻结构树 / 破坏性动作给选择 / Qt 对象必须有活着的 QApplication**（R117）；
    **标记能说话 / 体检覆盖所有按 ID 指向的结构 / 选择顺序是用户意图 / 不连续就拒绝**（R116）；
    **诊断落在几何上 / 一行坏数据不许让整张报告失效 / 模式的真相在会话 / 文件类型看内容**（R115）；
    **画出来的和能选中的是同一份几何 / 拾取偏好可预期**（R114）。
13. **一个概念一个数 / 局部化与计数同源 / 测量只读 / 多闭环体积断言求和 /
    再拉一次不复制已建体 / 尺寸单位三分**（R107–R112）。
14. 每轮结束照旧：定向 + 定向回归批 + 全量回归 + 快照 `--check`（两种解释器）+ 同轮文档 + 提交推送。
