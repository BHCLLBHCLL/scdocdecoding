## E. 口径（R114 起沿用）

1. **引用名要能被发现**（R113）：`dimN` / `S1_dimN` 的写法必须在树上写出来，否则等于没实现（纪律 91）。
2. **命名空间按需展开**（R113）：跨草图引用只拉被点名的草图，**候选表达式**里点名的也算。
3. **循环点名要有入口视角**（R113）：入口草图用 `#N`，其它草图用 `S1#N`。
4. **一个概念一个数**（R112/R113）：拾取半径 = 捕捉半径；焊接容差独立于捕捉（默认 0.1mm）。
5. **模型里有的东西树里必须看得到**（R113）：只有草图没有实体时也要列出草图。
6. **局部化与计数同源**（R112）：`len(dependent) == rows − rank` 构造性成立。
7. **测量只读、只报开着的缝**（纪律 85 / R112）；**多闭环体积断言必须求和**（R107）。
8. **尺寸单位三分**（R110）：约束里数值是米、表达式与 `dimN` 是毫米、API/UI 传入是毫米；
   换算只在 `dimensions()` 与 `_solver_rows()` 两处。
9. **再拉一次不复制已建体**（R112）：同一草图二次拉伸按 loop 原地更新旧体。
10. 每轮结束照旧：定向 + 定向回归批 + 全量回归 + 快照 `--check`（两种解释器）+ 同轮文档 + 提交推送。
