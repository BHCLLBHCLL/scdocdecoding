# R65 轮次交付记录（2026-09-12）

> 规则：每完成一轮改进即重新基线并产出**下一编号**的规划。本轮（R65）执行 P339：**裁剪片真四面体化**。
> 交付：`boundary="tets"` —— 边界片按质心扇形分解为**真四面体单元**（可数）；**同时撤回计划里的"二阶收敛"承诺**，用实测数据改写目标。

## 1. 交付内容（`scdm/mesh.py`）

| 项 | 实现 |
|---|---|
| 边界片 → 四面体 | `tetrahedralize_piece(piece, deflection)`：质心 + 逐边界三角形 ⇒ 每三角形一个四面体；退化三角形跳过并计数 |
| 填充模式 | `tet_fill(..., boundary="tets")`：内部格 6 四面体 + 边界片扇形四面体；**默认仍 voxel**（R62 数字不动） |
| 弦差与格距绑定 | `deflection` 缺省 = `cell×0.02`（扇形弦差随格距走） |
| 统计 | 新增 `boundary_tets / boundary_tet_volume / boundary_tet_degenerate`；`volume_clip` 在 tets 模式不再叠加边界体积（否则**双重计数**） |

**可数验收（实测）**：立方体 `boundary="tets"` → 单元数 = `6×实体格 + 边界四面体`、退化 0、体积 rel ≤ 1e-6（平面扇形精确）；
球体：每片扇形体积与**精确裁剪体积**之比 0.986（1.4% 内，且方向正确——弦差向内切）；两个误差（扇形网格 vs 裁剪精确）并列报出，谁也不藏。

## 2. 撤回"二阶收敛"（本轮最重要的结论）

计划写的是"误差随格距**二阶**收敛（半格 → 误差约 1/4）"，实测**不成立**，原因写清楚：

- 弦差扇形的体积误差 ≈ `∫sagitta·dA` —— 对**弦差是一阶**，把弦差绑到格距（`d=0.02c`）后误差与格距同阶，
  细格下甚至被别的项盖过（半格误差比 1.46 / 0.19）；
- 弦差序列（格距固定 5 mm）：4e-4 → 1.95e-2、2e-4 → 1.83e-2、1e-4 → 1.12e-2、5e-5 → 6.67e-3，
  比值 1.07 / 1.63 / 1.68 —— **单调下降但不是干净的 2×**（扇形星形性假设、布尔片提取与弦差三项混在一起）。

因此本轮把目标改成三条**可验证**的：①真四面体单元可数（= 6×实体格 + 边界三角形数）；②每片扇形体积与精确裁剪体积 5% 内且方向为"向内切"；
③误差随弦差**单调下降**。二阶收敛作为**未达成项**写进 R66（连同"要么用精确裁剪体积但不出单元、要么出单元但带一阶弦差误差"的取舍）。

## 3. 新增纪律

82. **收敛阶必须写明"对什么量、按什么尺度"**。"误差二阶收敛"若不指定度量（体积？单元尺寸？弦差？）就是不可判定的承诺——
   R65 实测：弦差扇形的体积误差对弦差是一阶，绑到格距上就不收敛。写验收时先写清度量，再写阶数。
