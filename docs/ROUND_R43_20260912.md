## 契约清单（实测，`scdm/sheetmetal.py`）

| 类别 | 函数 |
|---|---|
| 折弯计算 | `bend_allowance(angle_rad, r_inner, k, t)`、`bend_table_entry(material, thickness_mm)`、`hem_flange_offset(t, r_inner=None)` |
| 造件 | `bend_from_flat(width, t, len1, len2, angle_rad, r_inner, k)`、`hem(width, t, len1, hem_len, ...)`、`jog(width, t, len1, web_h, len2, ...)` |
| **面级成形** | **`bead_groove(solid, face, radius, length=None, ...)`** ← 百叶/敲落应**镜像这个签名** |
| 展开/分析 | `flat_pattern(solid, k, bend_lines)`、`flat_pattern_dxf(...)`、`unfold(solid, k)`、`detect_bends(solid, min_angle_deg)` |
| 修复 | `rip(solid, face, gap)`、`corner_relief(...)`、`bend_relief(...)` |

**落点结论**：`bead_groove` 是“在面上做成形”的既有范式（面对 + 参数 + 切削/加料），
因此 `louver(solid, face, length, width, height, origin=None)` 与
`knockout(solid, face, diameter, web=..., origin=None)` 都按它的形状实现，
并复用 `_face_frame`/`cut` 的内核路径（与孔族/凹坑一致）。

## 影响（写进 R44 规划）

1. **百叶**：矩形开口 + 抬起唇边 → 闭式体积 = 开口面积×板厚 ± 唇边体积，可给“开口面积×t”为主判据；
2. **敲落**：圆形/矩形开口 + 保留细筋（web）→ 几何上是“带 n 条筋的环切”，判据用“切除面积占比”；
3. 两者都必须**与展开兼容**：`flat_pattern`/`unfold` 不应因成形特征失败（需在 R44 加一条“展开仍成功”的断言）。
