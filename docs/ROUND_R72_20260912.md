> 规则：每完成一轮改进即重新基线并产出**下一编号**的规划。本轮（R72）执行 P358：**导入保真 ref 族攻坚**。
> 交付：逐项可数的**差异表**（面 + 边 + 自由边/自由环 + 分支）、三条候选修法的**否证**、产品口径升级（ref 族四元组），

## 1. 差异表（六个官方样例，逐项计数）

完整表见 `docs/REF_FAMILY_DIFF_TABLE.md`（由 `tools/ref_family_diff.py` 生成），分析见 `docs/REF_FAMILY_DIFF.md`，
机器可读记录 `docs/ref_family_diff.json`。要点：

| 事实 | 数字（实测） |
|---|---|
| ref 族规模 | SampleModel4 **52** 面、samplemodel2 **20** 面，其余 4 个样例 **0** |
| ref 族重建/未重建 | SampleModel4 **19/33**（无边界边 **6**）、samplemodel2 **19/1**（0） |
| ref 族曲面载荷 | 52/52 只有 `ref`（无 `nubs`/`nurbs`/`exactsur`） |
| ref 也落在**边**上 | SampleModel4 54 条（13 有载荷 / 41 仅 ref）、samplemodel2 40 条（2/38） |
| **自由边 / 自由环** | SampleModel1 **270/84**、SampleModel4 **441/112**、samplemodel2 **3542/547**、samplemodel3 **0/0**、samplemodel5 **0/0**、samplemodel6 2/2 |

第 5 行是本轮最重要的发现：**面数精确 ≠ 实体封闭**。SampleModel1 的 109/109 面全部重建，却有 270 条自由边、
84 个自由环——因为它的曲面是按**包围盒裁片**（`重建分支` 列 44 rebuild / 65 polygons），相邻片的边界不是同一条边，缝合接不上。
这条账（84 + 547 个环）比 ref 族（33 个面）**大一个量级**，已登记为 R73 的 P362。

## 3. 已修的那一项（产品口径）

`import_report` 从"一句话警告"升级为**可数四元组**，两个报告分支（多部件 / 单模型）都带（纪律 84）：

| 键 | 含义 | SampleModel4 实测 |
|---|---|---|
| `ref_faces` | 引用 ref 间接曲面的面数（旧键，保留） | 52 |
| `ref_built` | 其中仍由边界曲线重建的 | 19 |
| `ref_unbuilt` | 其中未能重建的 | 33 |
| `ref_no_boundary` | 其中**连边界边都没有**的 | 6 |

警告文本随之可数：`52 个面引用 ACIS ref 间接曲面（该类曲面的数据不在本 part）：其中 19 个仍由边界曲线重建，33 个未能重建（含 6 个无任何边界边）`。
GUI 侧 `ref_family_hint()`（Qt-free，一处措辞）供部件树/状态行使用：` · ref 52（未重建 33，无边界 6）`。

## 5. 新增纪律

86. **"修不了"必须附否证表**：每个想得到的候选修法都要给一次**可复算的实测否证**（命中 0 / 全部拒绝 / 数字不变），
    否则"不能修"只是没试过；并且必须把**已修项**与未修项分开登记。
