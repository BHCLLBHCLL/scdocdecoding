## 第一步：仪器化诊断（不再猜）

对模型 2 面 8/194 复算圆柱分支的每一步，一次读出真相：

```
face 8  kind cone(零半角=圆柱)  radius 0.03  fbox 0.060 x 0.049 x 0.056
  hull  [(-0.0402,-0.0245), (0.0402,-0.0245), (0.0402,0.0245), (-0.0402,0.0245)]
  arcs  [(2.1847, 1.9139), (5.3263, 1.9139)]     <- 两条弧！
  pieces 2
```

**根因**：投影凸包是**半高 0.0245 < 半径 0.03** 的窄带，圆被裁成**左右两段互不相连的弧**（各 1.91 rad）。
圆柱分支“一条弧建一个面”的写法于是**一个面变两个面**——正是那 2 个 surplus。
（R13 的两条假设（预筛、退化凸包）之所以无效，是因为真因是“**多条弧**”，不是“一条过宽的弧”。）

## 第二步：定点修复

当解析窗口给出 **≥2 条弧**时，用**记录 bbox** 消歧：逐弧建面并算采样 bbox 距离，只保留最优的一条弧再建面。
代价 O(2) 次建面 + 采样，且只在“多弧”这种罕见情形触发（导入时间未升反降：6.80 s）。
