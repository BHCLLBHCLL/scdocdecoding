## 2. R60 工作项（P319–P322）

### P319 · 材料库与零件属性（最高优先，R58/R59 顺延两次）

- **动作**：材料表（牌号/密度/弹性模量/泊松比）+ 零件属性（材料/质量/表面积/自定义字段）；
  质量 `= 体积 × 密度`（闭式断言）；BOM 行带材料与质量；`.scdm` 往返（清单版本 +1）。
- **验收**：质量闭式（rel 1e-9）+ 属性与材料往返一致 + BOM 联动（改材料 → BOM 与质量同步）+ 非法（未知材料/负密度）。**成本**：1 天。

### P320 · CAE 网格域首批（面网格 + 单元质量闭式）

- **动作**：对实体做面网格（复用 `scdm.facets` 的分面/焊接）并给出**可数的质量指标**：
  三角形面积和 = 表面积（闭式对拍）、长宽比分布、最小角、雅可比下限；网格统计导出（JSON/CSV）。
- **验收**：面积和与 `K.area` 一致（rel 1e-6，网格离散误差显式给出）+ 退化三角形计数 = 0 + 非法（空形状/零尺寸）+ 回放。
- **成本**：1.5 天。

### P321 · 可选补测（内存/帧率）｜P322 · 每轮维护（必做）

- P321 沿用 `tests/test_perf_budget.py` 口径；P322 快照/CI/口径同步 + 编号递增 + 轮次记录同轮补齐（纪律 65）。
