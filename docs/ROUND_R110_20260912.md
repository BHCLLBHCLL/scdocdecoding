# R110 轮次交付记录（2026-09-12）——A-1 半径尺寸 + A-2 尺寸表达式 + A-5 活动草图持久化

> 三项都让"草图 → 实体"更像一个**可驱动**的系统：圆能用数字改大小、尺寸能写成表达式并随参数表重解、
> 文档记住你正在编辑的草图（存盘后仍指向它）。

## 1. 交付清单

| 文件 | 类型 | 内容 |
| --- | --- | --- |
| `scdm/sketch.py` | 库层 | `read_circles()`（求解器的半径变量布局 `{圆心点序号: 半径}`）；`write_points(sk, pts, circles=None)` 现在把**半径写回曲线**（来自手柄点距离，或来自求解器的半径映射）——此前驱动"圆心→手柄"距离只动手柄，圆不会变大 |
| `scdm/sketchmode.py` | 库层 | `DIM_KINDS = ("dist", "radius")` + `_dim_value_index()`（两种约束形状）；`dimensions()` 单位口径统一（数值行存米→报 mm，表达式行本身就是 mm）；`_solver_rows()` 把表达式解析成米后再交给求解器；`redrive_expressions()`（参数表变化后重解所有表达式尺寸）；`set_dimension()` 支持表达式与 `RADIUS`，并按 `circles` 映射验证驱动量；`resolve_active()` 回落到 `kdoc.active_sketch` |
| `scdm/kdoc.py` | 数据层 | `KernelDoc.active_sketch`（正在编辑的草图） |
| `scdm/io_project.py` | 持久化 | 工程清单记 `active_sketch` 并在读入时恢复 |
| `scdm_gui.py` + `scdm/gui/params.py` | 命令层 | 进入/编辑草图时写 `active_sketch`；尺寸编辑框接受**表达式**（非数字即当作表达式）；参数对话框应用后自动 `redrive_expressions` + 同步依赖实体，状态栏报"重解 N 个草图尺寸" |
| `tests/test_sketch_dims_r110.py` | 新增 | 8 条：圆经手柄驱动（半径写回）、RADIUS 约束列出并驱动、数值行按 mm 上报、表达式驱动与参数重解、坏表达式回滚、活动草图工程往返、会话优先于文档、参数对话框重解 |

## 2. 验收实测

| 项 | 实测 |
| --- | --- |
| 圆（手柄距离） | ⌀4×10mm 基准 **1.25663706e-07**；驱动 2→3mm → 曲线半径写回 **0.003**；同步后体积 **2.82743323e-07** vs 闭式 2.82743339e-07（rel 6e-8） |
| 圆（RADIUS 约束） | `dimensions()` 列出 `('radius', 2.0)`「半径 2mm」；驱动到 3.5mm → 半径 **0.0035** → 体积 = `π·3.5²·10`（rel 1e-6） |
| 单位口径 | 约束里存 0.002（米）→ `dimensions()` 报 **2.0 mm**（此前的 0.008m 被显示成 "0.008mm"，本轮修正并加测试锁住） |
| 表达式尺寸 | `2*d`（`d=5`）→ 10mm → 体积 **4e-07**；把 `d` 改成 10 → `redrive_expressions` → 20mm → 体积 **7.99999999e-07**（=20×8×5mm³）；约束里仍存字符串 `2*d` |
| 坏表达式 | `2*nope` → 拒绝「表达式无法求值：未知参数 'nope'」，约束与几何**全部回滚** |
| 活动草图 | 拉伸某草图 → `kdoc.active_sketch` 记下它 → 存盘重开后 `resolve_active(back, None)` 仍返回该草图（无 GUI 会话），并可在重载文档里继续驱动到 ⌀8（体积闭式） |
| 参数对话框 | `apply_param_text(doc, "d = 10", "", 1000)` → `redrive.redriven == 1` → 体积 **8e-07** |

## 3. 边界（转 R111）

1. **到面进库层**（A-3）：到面仍只在 GUI（要选中面 + 视口），库层只接受高度。
2. **草图镜像/阵列**（A-4）：草图页签仍复用 Design 页命令，没有草图专属命令。
3. **按捕捉半径焊接**（A-6）：焊接容差固定 0.1mm，未跟随视口捕捉半径。
4. **表达式只支持参数表**：不支持引用其它尺寸（如 `= 2*#dim3`），也没有"尺寸间约束"的 UI。
5. 装配线仍在等 **B-1 装配层级/局部坐标系**。
