## P0 一致性闭环（1–2 天，先做）

### P0-1 特征编辑闭环：GUI 参数 → 特征参数 → 重放
- **现状证据**：`features.py` `FeatureStack`（每体）+ `FeatureHistory`（文档级）+ `KernelDoc.replay_document()`
  已存在，录制点 20+（`scdm_gui.py` 1085/1110/1252/1278/1320/1352/1385/1431/1494/1528/1560/1594/1623/1648/1751/1791/
  3691/3696`、`scdm/tools/direct.py` 102/202、`scdm/scripting.py` 618）；但 GUI 的参数表只驱动
  `kdoc.parametrics`（box/cylinder），**改特征参数不会重放特征栈**。
- **做法**：把 `det.params` 参数表与 `FeatureStack` 打通（列出可编辑特征 → 改值 → `apply()` 重放 →
  体/网格刷新），并让 `edit.undo` 记录"参数编辑"这一步。
- **验收（可复算）**：箱体 20×20×10 → 孔 ⌀5 通孔，改 ⌀ → 体积 = `V_box − π(d/2)²·t` 两次都与闭式一致；
  撤销后体积回到前一个闭式值；`FeatureStack` 序列不变（长度与 ops 列表断言）。
- **八层**：特征（新增可编辑参数白名单）→ 脚本 op（`op_param_edit` 可选）→ 目录（`det.params` 已有，行为升级）
  → 回放测试 → 视口标记（重放后重建 tessellation）→ 快照。

### P0-2 数字单一来源：两个工具互校（纪律 84）
- **现状证据**：`tools/gen_devplan_snapshot.py` 与 `tools/state_inventory.py` 各自统计页签/命令/live/测试数，
  本轮已让两处口径一致（18 / 164 / 178 / 29 / 177 / 680），但**仍是两份实现**。
- **做法**：一条交叉校验测试：`snapshot_rows()` 里的四个数与 `state_inventory.command_face()`、
  `test_face()` 必须相等；不等即失败并指出是哪一格。
- **验收**：故意改一处目录后，该测试在本地复现失败（可复现命令写进测试 docstring）。
- **八层**：工具层 + 测试守卫（无产品改动）。

## P1 深度闭环（每项 2–5 天）

### P1-1 装配配合的 GUI 闭环
- **现状证据**：`mates.py` 7 类运动副 + `DOFS` 表 + `solve_transform()`；`kdoc.mates` 只存
  `{"type","a","b","value","angle","slide"}`；GUI 只有 `asm.mate` 一键命令，无自由度/欠约束反馈。
- **做法**：配合创建/编辑对话框（类型 + 参照 + 驱动值）→ 调 `solve_transform` → 写回 `Component.transform`
  → 状态栏报告「剩余 DOF / 过约束」。
- **验收**：`RIGID/REVOLUTE/CYLINDRICAL/PLANAR/BALL/SCREW/DISTANCE` 七类各一条单测断言剩余 DOF = `DOFS` 表值；
  过约束（两条刚性）必须报错而不是静默。
- **八层**：内核无改动 → 特征/装配数据模型（已有）→ 目录 `asm.mate`（行为升级）→ GUI 对话框 → 回放测试 →
  视口标记（配合后姿态）→ 快照。

### P1-2 配置语义扩展（替换件 / 驱动尺寸 / 对比）
- **现状证据**：`Configuration` 目前只有 `hidden_components / suppressed_bodies / transforms /
  properties / quantities`；无替换件、无驱动尺寸、无配置对比。
- **验收**：两个配置的 BOM 行数与质量各自等于快照值（可复算）；切换配置后可见体数 = 配置声明值。
- **八层**：`kdoc` → `asm.config` / `asm.config_apply`（行为升级）→ 详细页 BOM 联动 → 测试 → 快照。

### P1-3 工程图标注补齐（孔标注 / 中心线 / 粗糙度 / 剖面线）
- **现状证据**：`annotation.py` 394 行 / `Leader` / `GdtFrame` / `Datum` + `dimchain.py` 尺寸链；
  DXF/SVG 双导出已端到端断言（R94）。缺孔标注、中心线、表面粗糙度、剖面线填充。
- **验收**：一张含 4 类标注的图，DXF 与 SVG 的实体计数各等于闭式条数（同 R94 模式）。
- **八层**：`annotation.py` 新增类 → `drawing.py` 导出 → `det.*` 命令 → GUI 图纸画布 → 回放测试 → 快照。

### P1-4 钣金折弯表 + 展开图工程化
- **现状证据**：`bend_table_entry` / `bend_allowance` 已有；`flat_pattern_dxf` 有；缺按材料/厚度的
  K 因子表与展开图注释（折弯线/方向/角度）。
- **验收**：同一零件在两张表的 K 因子下展开长差 = `ΔBA = θ/2·(t·K₂ − t·K₁)` 闭式；DXF 折弯线数 = 折弯数。
- **八层**：`sheetmetal.py` → `op_sheet_unfold` → `sheet.unfold` / `sheet.flat` → 测试 → 快照。
