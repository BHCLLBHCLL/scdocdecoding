## 2. R55 工作项（P299–P302）

### P299 · 图纸标注：引线 + 形位公差（最高优先，R54/P296 顺延）

- **动作**：引线标注（箭头 + 折线 + 文本，锚点复用 `scdm.snaptools` 的端点/中点/交点/网格吸附）；
  形位公差框（符号/公差值/基准，如 `⌖ Ø0.05 A`）；两者都进 `Dimension` 同级的标注列表，
  随 SVG/DXF 导出，且沿用 R52 的偏移快照 undo。
- **验收**：锚点吸附闭式（1e-12）+ 标注**不入几何**（体积/包围盒不变）+ 导出文件含标注层 + undo/redo 往返一致。**成本**：1 天。

### P300 · 钣金接缝 junction / 撕裂补项

- **动作**：接缝（两折弯相交处的释放/连接）几何闭合式（去除量 = 三角形/矩形截面×板厚）；
  沿用面框架与 rip/corner_relief 的既有路径。
- **验收**：闭式 + 非法 + 极端 + 回放 + 展开数值等价（纪律 60/67/71）。**成本**：1 天。

### P301 · 可选补测（内存/帧率）

- **动作**：沿用 `tests/test_perf_budget.py` 口径补一次内存峰值与帧率基线。**成本**：0.5 天（可选）。

### P302 · 每轮维护（必做）

- 快照/CI/口径同步（`tools/gen_devplan_snapshot.py --update`）；编号递增；轮次记录与规划同轮补齐（纪律 65）。
