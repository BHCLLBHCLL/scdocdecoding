## 2. R33 工作项（P193–P198）

### P193 · 攻丝孔命令与视口示意（最高优先，P187 收尾）

- **动作**：①`prep.hole` 增加“攻丝”选项 + 公称/螺距输入，走 `op_hole_tapped` 并记录到特征历史；
  ②视口用 `thread_lines` 画牙型示意（独立 actor，不进拾取/BVH，不进布尔）；③脚本回放端到端断言（录 3 步 → 回放 → 体积一致）。
- **验收**：命令级行为测试 1 条（含非法螺纹提示）；回放体积 == 直调（rel 1e-6）；示意 actor 存在但 `K.volume` 不变。
- **成本**：1–1.5 天。

### P194 · 成形族（凸台/凹坑/百叶/敲落）

- **动作**：套用“闭式体积 + 非法参数 + 极端参数”模板；凹坑/百叶与 `sheetmetal.py` 协同。
- **验收**：每特征一条闭式 + 一条非法断言。**成本**：1.5–2 天。
