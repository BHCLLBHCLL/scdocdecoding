## 交付：环面窗口采样网格 7 → **13**，切分 20 → **4**

**诊断（本轮探针，逐候选打印采样 bbox 与记录 bbox 的逐轴差）**：
模型 2 的 8 个切分环面里，**正确窗口本来就在候选表里且逐轴差为 0**，例如：

```
face 253  uv [-0.0, 1.5723, -3.1416, 3.1416]
  cand [-3.142, 3.142, -0.0, 1.572]  dlo [0,0,0]  dhi [0,0,0]   <- 完全吻合
  cand [-0.0, 1.572, -3.142, 3.142]  dlo [-0.04, 0, 0.524] ...   <- 错读法
```

被拒的原因是**采样网格太稀**：7 点在整圈片上取不到 90° 的极值（y/z 极值恰在 90° 倍数处），
采样 bbox 因此偏小 → 距离超阈值 → 退回布尔裁剪。13 点（步长 30°）正好命中极值。

**改动**：`_face_uv_samples` 默认网格 7 → **13**（仅 torus 的窗口判定使用，见 R9 的 `accurate=(kind == "torus")`）。
