## 3. 边界（转 R116）

1. **冲突几何只标点与线段**：不标冲突类型（尺寸/垂直/相切），也不区分冲突与冗余的颜色。
2. **体检只报尺寸引用**：不检查别的悬空（如 mates 指向已删组件、named selection 指向已删面）。
3. **删体不弹确认**：闭环消失即删（靠撤销恢复）；不会把体降级为「断开参数的普通实体」。
4. **`_solver_rows` 跳过坏行**：坏行不参与求解，因此它原本占的约束在这轮里不存在——DOF 会相应变大（诚实但需注意）。
5. **A-3 尺寸驱动预览、A-4 拉前重解、A-5 沿曲线多段/偏移、A-7 三维模式选草图** 仍顺延；装配线仍在等 **B-1**。

## 4. 口径与纪律（R115 新增）

1. **诊断落在几何上**：说「第 5、7 条在打架」不够，要能给出**点与线段**（`conflict_geometry` 保持 Qt-free，
   于是 headless 也能断言映射本身，而不只是断言「有没有画」）。
2. **一行坏数据不许让整张报告失效**：无法解析的表达式**跳过并记录**（`skipped`），DOF/冲突照常给（本轮修的 `_solver_rows`）。
3. **模式的真相在会话，不在工具**：`_exit_sketch` 原先按「工具模式是不是草图」判断，
   而点「三维」会先把工具模式改掉 → 整段收尾（同步/网格/页签/chip）静默跳过（本轮修）。
4. **文件类型看内容，不看扩展名**：工程是「带 manifest.json 的 zip」，所以改名另存也认得（本轮修）。
5. **删要有据、可回退**：闭环消失才删体，且必须点名（`removed` 带原因）、必须能靠快照/撤销回来。

## 5. 本轮修掉的两个真 bug（顺带）

1. **点「三维」不会收尾**：`on_command` 先把工具模式切成 `mode.3d`，`_exit_sketch` 再用 `_mode()` 判断
   「刚才是不是在草图」→ 恒为假 → **同步、网格、页签、chip 全部跳过**（草图改动不会落到实体上）。
   修法：以 `self._sketch_session` 为准。R105–R114 的测试没覆盖到，是因为它们断言的 `_mode()` 恰好由工具模式驱动。
2. **工程文件改名另存后打不开**：Save-As 的过滤器里有 `.scdoc`，而打开时按扩展名分派 → 工程被交给
   官方文档解析器 → 失败后弹**模态错误框**（headless 下直接 access violation）。修法：按内容识别（zip + manifest.json）。
