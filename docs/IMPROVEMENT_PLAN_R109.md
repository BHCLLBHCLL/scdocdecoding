## E. 口径（R109 起沿用）

1. **顶点焊接**：只有"顶点"（line/rect/poly 的端点）参与焊接，圆心与半径手柄永不参与；焊接是幂等的纯约束操作，
   不改几何，且**先焊后求解**（`set_dimension` 内自动执行，失败回滚时保留焊接）。
2. **落座方式**：`one` / `symmetric` / `reverse` 三者**同厚度同体积**，只有相对草图面的位置不同；
   特征里记 `mode`，重放与创建必须走同一个 `place_extrusion`（避免"建的时候在中间、重放在起点"）。
3. 每轮结束照旧：定向 + 全量回归 + 快照 `--check`（两种解释器）+ 同轮文档 + 提交推送。
