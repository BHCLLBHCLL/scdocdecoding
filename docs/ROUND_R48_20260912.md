# R48 轮次交付记录（2026-09-12）

> 规则：每完成一轮改进即重新基线并产出**下一编号**的规划。本轮（R48）执行 R47 规划中的 P265：**唇边加料**。
> 交付：`louver(height>0)` 把抬起的唇板 fuse 回开口，闭式变为 `L×W×(t−h)`；3 条新测试。

## 改动（`scdm/kernel.py::louver`）

```python
out = cut(solid, prism(profile, n*span))            # 开口（R45 的定向棱柱）
if height > 0:
    lip = prism(face_from_polygon(面内矩形 at base), n*height)
    out = fuse(out, lip)                            # 唇板与槽零重叠
```

要点：唇板**同底面积、坐在面上**，因此与已切除的槽不重叠——闭式可精确写成 `L×W×(t−h)`，无需处理布尔碎块；
`height > 板厚` 显式 `KernelError`（否则唇边会“填穿”板材）。

## 测试（`tests/test_forming_p247.py` 增至 8 项）

①无唇闭式；②有唇闭式；③**两者之差 == 唇边体积**（rel 2e-3）；④唇高超板厚 → 拒绝；⑤极端 `height == t` → 槽被完全填平，体积回到原板（rel 1e-3）。
