## 2. R66 工作项（P343–P346）

### P343 · 体网格精度路线选择（最高优先，R65 未达成项）

- **动作**：写一张**误差预算表**（体素 O(cell) / 裁剪精确但无单元 / 弦差扇形有单元但一阶 / 目标二阶），
  并选一条路线落地：**边界片按裁剪面精确分解**（把片的每个平面面片与曲面片分别处理，或对片做约束 Delaunay），
  使体积误差对**格距**二阶（半格 → 约 1/4），度量写死为"体积相对误差 vs 格距"（纪律 82）。
- **验收**：预算表 + 选定路线的实现 + 半格误差比 ≥ 3（可数）+ 单元可数 + 退化 0 + 回放一致。**成本**：1.5 天。

### P344 · 焊接符号元数据面板（`weld.symbol` 占位转 live）

- **动作**：把已有 `WeldSymbol` 模型接到面板（选焊件成员 → 类型/尺寸/长度/间距 → 写入 `Weldment.symbols`），
  树节点/状态栏显示，`.scdm` 往返；占位 3 → 2。
- **验收**：符号往返一致 + 指向不存在成员报错 + 面板路径可测 + 占位计数下降。**成本**：1 天。

## 4. 纪律（延续 + R66 新增）

82. **新增**：**收敛阶必须写明"对什么量、按什么尺度"**。"误差二阶收敛"若不指定度量（体积误差？单元尺寸？弦差？）就是不可判定的承诺。
    R65 实测：弦差扇形的体积误差对**弦差**是一阶（`∫sagitta·dA`），绑到格距上就不收敛；写验收先写度量，再写阶数。
