## 3. 边界（转 R126）

1. **目标仍是手打**：没有「从当前文档里挑参数/草图/尺寸」的列表，选中多行时也只能给同一个目标（库层的 `{id: 目标}` 逐行映射界面还用不到）→ 转 A-11。
2. **`--check` 不比像素**：视口全空也能过（`3d=True` 只是记录，不是断言）→ 转 A-12。
3. **A-4（尺寸驱动预览）、A-6（三维模式选草图曲线）、A-7（交互式预览清单）、A-8（点标记样式与其余调用点）** 顺延。
4. **CI 那一步只能在 CI 上真跑**：本地只能保证工具 exit 0 与 YAML 里有这一步。
5. **C-8 余下两张参考图**（草图选择 / 修复）未补；装配线仍等 **B-1**。

## 4. 口径与纪律（R125 新增）

1. **页面给的就是库收的**：选项页列出的三种目标 = 库层认识的三种写法；拼好的字符串直接交给库判，
   拒绝要指向真正的原因——界面不自己发明一套校验。
2. **默认值必须仍是历史行为**：选项页的第一种选择就是这一页从前干的事（草图序号），否则老用户按回车就换了语义。
3. **工具要能自证**：批次清单自检（路径存在 + 被收集 + 草图轮次不缺），旁车记够事实。
4. **校验要能真的红**：新增的比对字段必须有一条用例证明「只错这一项也会 stale」，否则它只是装饰。
5. **检查要进流程**：`--check` 不能只活在本地——CI 里跑一次，过期就挡住构建。
