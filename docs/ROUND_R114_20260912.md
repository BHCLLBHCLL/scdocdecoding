## 3. 边界（转 R115）

1. **选择集是「最后点击 + Shift 加选」**：没有框选、没有多选面板、没有「全选同类」（如所有直线）。
2. **高亮只在草图模式**：退出模式即清空；三维模式下选不中草图曲线（草图不作为可选实体参与三维选择）。
3. **沿曲线阵列的路径 = 一条草图曲线**：不支持多段路径连接、不支持「按数量 + 总弧长」的第二种口径、不支持相对路径起点的偏移量。
4. **被引用草图删除**只做诊断，不自动修复（不改成数值、不切换引用）；草图序号不复用，故不会「指到别的草图」。
5. **拉之前不重解表达式尺寸**（R111 口径沿用）；**删闭环不删体**（R112 口径沿用）。
6. **A-3 尺寸驱动预览、A-7 冲突高亮到视口**仍顺延（A-7 现在只差「把 `conflict_cons` 的几何喂给选择集高亮」）；装配线仍在等 **B-1**。

## 4. 口径与纪律（R114 新增）

1. **画出来的和能选中的必须是同一份几何**：草图显示与选择高亮共用 `_curve_geometry`，
   否则「我明明点的是这条边」会变成不可复现的争论（纪律 84/91）。
2. **拾取的偏好要可预期**：顶点在容差内、且不比边远 2 倍以上时胜出——点角得角、点中段得边；
   圆的采样点不是用户顶点（圆心才是）。
3. **按折线走就是按折线说**：沿曲线阵列的切线取路径折线的弦方向，误差随采样收敛；
   测试因此断言「收敛」而不假装 1e-12（纪律 87：量出来的数与采样相关就要说出相关性）。
4. **失败要指到具体对象**：跨图引用失败点名草图与序号（「被引用草图 S2 已不存在」/「S1 没有尺寸 #3」），
   并在树上标「悬空」——「未知参数」不是可修的诊断。
5. **headless 没有 3D 场景**：视口高亮只能在有 VTK 场景时验证，因此把「几何来源」做成可静态测试的函数，
   测试断言几何而非 actor（本轮据此调整了三条测试）。
