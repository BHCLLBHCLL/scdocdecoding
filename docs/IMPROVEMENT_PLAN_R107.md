## A. 草图/建模链（承 R106）

| # | 项 | 现状证据 | 验收（可复算） |
| --- | --- | --- | --- |
| A-1 | **多轮廓分区拉伸** | `sketch_outline` 取一个闭环；一张草图多个环只拉伸外轮廓 | 两环草图 → 两个实体（或一个带两处凸台的体），体积 = Σ环面积×高（闭式）；各自带 `sketch` 特征 |
| A-2 | **精确圆/样条截面拉伸** | 圆拉伸 1.2546e-07 vs 闭式 1.2566e-07（多边形近似 0.16%） | 圆拉伸 = `πr²h`（rel 1e-6）；样条截面按面积闭式对拍 |
| A-3 | **尺寸标注驱动草图** | `con.dim` 只写回曲线；改标注值不能反向改尺寸 | 改 `con.dim` 的值 → 矩形尺寸随之改变 → 体体积 = 新 `w·h·t`（闭式）；solve_report 里 DOF 不变 |
| A-4 | **拉伸选项接入** | `sketch` 特征只有高度 | 反向/两侧/到面：体积 = `w·h·t`（反向同值）/ `2·w·h·t/…`（两侧）/ 到面 = 面距闭式 |
| A-5 | **草图镜像/阵列** | 草图页签复用 Design 页命令 | 草图模式下新增 `sketch.mirror` / `sketch.pattern`，三维模式下 refuse；曲线数可数 |
| A-6 | **模式切换进撤销栈** | 自动越界不计入 undo（R105 遗留） | 越界后一次 undo → 回到草图模式且活动草图恢复；redo 再回三维 |
| A-7 | **活动草图持久化** | `_sketch_session` 是内存态 | 存盘重开后 `resolve_active` 返回同一草图（清单记 `active_sketch`） |

## B. 装配与配合（承 R105/A 组）

| # | 项 | 现状证据 | 验收 |

| B-1 | **装配层级 / 局部坐标系** | 配合把 B 摆到 A 的当前帧后即结束；改 A 不带动 B | 两级链 A→B→C：移动 A 10mm，B、C 按链式矩阵更新（1e-12）；重放后体积不变 |
