## 3. 边界（转 R117）

1. **冲突标记不区分「哪一条是多余的」**：冗余标记只说它重复了，不指出它重复的是谁。
2. **体检只报悬空 ID**：不检查语义冲突（如两个配置矛盾、配合的自由度冲突），也不自动修复。
3. **沿曲线阵列的锚点 = 路径起点**：几何若不落在路径起点，副本会整体平移；链的**方向**由选择顺序优先决定（否则取能连完整条路径的方向），副本朝向随之。
4. **路径必须连续**（容差 0.1mm）：断开的曲线不会自动桥接。
5. **A-3 尺寸驱动预览、A-4 拉前重解、A-6 删体降级/确认、A-7 三维模式选草图** 仍顺延；装配线仍在等 **B-1**。

## 4. 口径与纪律（R116 新增）

1. **标记要能说话**：颜色区分状态、`label` 说出类型（「尺寸#5 冲突」而不是「#5」），
   几何按标记分开给（既给并集也给逐条），UI 与测试各取所需。
2. **体检覆盖所有「按 ID 指向」的结构**：尺寸、配合、命名选择、组、配置、实例；
   一处漏检就等于「文档看起来没问题」。
3. **选择顺序是用户意图**：路径链的方向优先按用户选择顺序，其次才按几何；
   方向不确定时测试断言**不变式**（锚点集合、方向集合），不写死具体端点。
4. **不连续就拒绝**：宁可说「相距 10mm」，也不要静默拉一条直线把路径接上。
