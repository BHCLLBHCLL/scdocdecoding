## 4. 口径与纪律（R126 新增）

1. **预览不改文档**：预览在副本上算；取消是「什么都不做」，所以状态条敢写「取消即不变」。
2. **预览与提交同源**：预览用的建体代码就是重放用的那段（`features.sketch_solid`）——两条路径不许各写一份。
3. **目标只有一套语法**：`S2` / `S2_dim5` / `param:d` / `expr:2*d` 都由库定义；界面里的选择器只是快捷方式，选中它写的就是那两个控件。
4. **「空」也要判过期**：声称有 3D 视口，就得有非背景像素；`ink=0` 直接 stale。
5. **历史行为优先**：本轮把目标框默认值设成非空，回归批立刻抓到 R120/R121 三条老用例（「树上挑的草图 / 手填序号」被顶掉），同轮改成默认留空后复跑全绿——默认值是行为，不是样式。
