## 3. 边界（转 R113）

1. **草图实体还不能当镜像轴**：只能关于草图两轴或显式直线镜像（视口里草图曲线尚不可选）。
2. **阵列只有线性**：没有圆周阵列 / 沿曲线阵列 / 阵列方向拾取。
3. **焊接容差与捕捉半径是两个数**（计划里写的「容差 = 捕捉半径」被实测否证，见纪律 1）：捕捉 5mm 是绘图辅助，焊接默认 0.1mm 且可配置。
4. **镜像/阵列只作用于 `curves`**：`construction` 构造线不参与（它们不是轮廓）。
5. **删闭环不删体**：闭环被删掉后其体仍留在文档里（同步报 failed 并保留），「删闭环是否删体」留待 R113。
6. **A-3 尺寸驱动预览、A-5 跨草图引用**仍顺延；装配线仍在等 **B-1 装配层级/局部坐标系**。

## 4. 口径与纪律（R112 新增）

1. **焊接 ≠ 捕捉**：捕捉半径是绘图辅助（视口 5mm），焊接容差是修复量（文档级、默认 0.1mm）。
   两者共用一个数的写法被实测否证：5mm 焊接会把相距 2mm 的两个轮廓并成一个（6 闭环草图塌成 3）。
   「0.5mm 缝在容差内焊成闭环」由**可配置的焊接容差**满足，不需要动捕捉半径。
2. **局部化必须与计数同源**：`dependent_rows()` 与 `_rank()` 用同一套 Gram–Schmidt 与阈值，
   `len(dependent) == rows − rank` 构造性成立——不允许「报了 1 条冗余却指不出是哪条」（纪律 84/87）。
3. **测量只报「开着的」缝**：忽略已重合的点对，否则三个角焊好的草图会把 0.0 当成缝（本轮修）。
4. **再拉一次不复制已建体**：同一草图二次拉伸按 loop 原地更新旧体、只新建缺的 loop；
   否则「镜像后照提示再拉」会得到重复实体（纪律 91：UI 的提示必须是能照做的）。
5. **拒绝要能照做**：闭环缺失时同时给出缝的大小**与**当前容差，用户才知道该调哪个数。
