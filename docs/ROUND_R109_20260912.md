# R109 轮次交付记录（2026-09-12）——A-1 捕捉容差焊接 + A-6 模式进撤销栈

> 两项都来自 R108 的残留：焊接只认"坐标完全相同"（真实绘制总差一点），以及越界切换模式不进撤销栈
> （按一次 undo 回不到草图）。本轮把两件事都补成**用户可感知**的行为，并且都有可复算验收。

## 2. 验收实测

| 项 | 实测 |
| --- | --- |
| 容差焊接 | 四角差 **0.1mm** 的四条线：`tol=1e-6` 只焊本来正好重合的 **1** 个角；`tol=1e-3` 补齐其余 3 个（共 4）；焊接后同一角的两点距离 **= 0**，闭环数 1 |
| 拉伸先焊 | `extrude_active` → `welded=4 / welded_moved=3`，产出 1 个体，体积 4.045e-07（按"吸附到组首"的绘制值，rel 2%） |
| 超容差诊断 | 端点相距 **0.5mm** → 拒绝并给出"最近的两个端点相距 **0.5mm**（未重合）"，`welded=0` |
| 撕开也能驱动 | 撕开草图 → 拉伸（自动焊）→ 补 H/V/DIST/FIXED → 驱动宽度 10→20mm：`dof=0`、闭环 1、同步后体积 **8e-07**（rel 1e-6）、`can_replay` 真 |
| **撤销回到草图** | 进草图（S1）→ `asm.mate`（自动越界 → solid）→ **undo → 回到 sketch 且仍是 S1、网格开**；**redo → solid、会话清空、网格关** |
| 进入本身可撤销 | `mode.sketch` → undo → solid；redo → sketch |

## 3. 两个"卡住才想明白"的点（写进口径）

1. **焊接必须吸附坐标，而不只是加约束**：只加 COINCIDENT 的话，几何仍差 0.1mm，`sketch_loops()` 的 1e-9 判据照样看不到闭环 —— 所以 `snap=True` 会把后出现的点移到组首（移动量 ≤ 容差，计入 `moved`）。
2. **恢复模式时不能再压栈**：`_apply_ui_state` 里如果让 `_exit_sketch/_begin_sketch` 正常压栈，`History.push()` 会截断 redo 栈（undo 之后就再也 redo 不回去）。加 `_applying_ui` 守卫解决。
   另外测试里 **QApplication 必须由模块级全局持有**：局部变量被 GC 后整个 app 连同所有控件被销毁，下一个测试就报 "wrapped C/C++ object has been deleted"（本轮踩到并已修）。

## 4. 边界（转 R110）

1. **半径尺寸**（`radius`）仍未开放（需求解器 `circles` 映射）；圆的尺寸目前走"圆心→半径点"的 DIST。
2. **尺寸表达式**（`w = 2*d`）未接 API/UI。
3. **草图镜像/阵列**未做（草图页签复用 Design 页命令）。
4. **活动草图持久化**（A-7）未做：重开工程后仍要从结构树双击进草图。
5. 焊接容差固定 0.1mm；"按绘制时的捕捉半径焊接"（更接近手感）没有再细分。
