## F. 口径（R129 起沿用）

1. **官方语料是尺子**（R128）：写它的是 SpaceClaim，读回它的也是 SpaceClaim；我们只读、只对照。
2. **读不出要分类计数 / 崩溃要变成数字 / 设置要立刻可见且活过重启 / 测试动过的全局状态要放回去**（R128）。
3. **预览要说全部 / before 必须取回 / 一个数一个来源 / 逐行输入要能逐行给 / 契约变了同轮改测试**（R127）。
4. **预览不改文档 / 预览与提交同源 / 目标只有一套语法 / 「空」也要判过期 / 历史行为优先**（R126）。
5. **页面给的就是库收的 / 默认值仍是历史行为 / 工具要能自证 / 校验要能真的红**（R125）；
   **画不出来就不算标记 / 校验不依赖平台 / 谁说的算**（R124）；
   **图要能重生成也要能自证过期 / 数字要能看见 / 标记与状态条同源 / 陈旧标记要清**（R123）。
6. **界面要追上库层 / GL 内容单独取 / 工具能离屏自检**（R122）；
   **挑选要有两个方向 / 目标从界面里点 / 前提错了要更正**（R121）；
   **批量要能挑 / 只读就是只读 / 两条路径合一**（R120）；
   **修复保留意图 / 破坏性动作先说后做**（R119）。
7. 每轮结束照旧：定向 + 定向回归批 + 全量回归 + 快照 `--check`（两种解释器）+ 同轮文档 + 提交推送。
