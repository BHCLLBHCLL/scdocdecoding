## 1. 标注模型（`scdm/annotation.py`）

| 项 | 实现 |
|---|---|
| 箭头样式 | `Leader.arrow` ∈ solid/open/none；`arrow_head()` 闭式：实心=三角形（首点=锚点、长 2.5×字高、半宽 0.8×字高），空心=两条倒钩，无=空表；方向随引线（折点）自动旋转 |

| 复合公差 | `GdtFrame.extra_rows`：每行 `{symbol, value, datums}`；`rows()/labels()` 逐行输出；框高 = 行数×单行高；`dividers()` 给行分隔线 + 单元格分隔线（有基准的行才有基准格） |
| 校验 | **构造即校验**（`__post_init__` → `validate()`）：类型/尺寸/代号/字高不合法一律在构造时抛错，不留半成品 |
| 往返 | 新字段全部进 `to_dict/from_dict`（旧数据缺字段时取默认，向后兼容） |

## 2. 导出与画布

`annotation_geometry()` 由 `(segs, text, at)` 升级为 `(segs, text, at, style)`：
style 带 `{layer, arrow, text_height, filled, rows}`，两个导出器与画布都据此绘制，不再认识具体标注类。
- SVG：元素带 `data-layer` / `data-arrow`，字号 = 字高×1000（mm），颜色按层（NOTE 蓝 / GDT 绿 / DATUM 棕）；
- DXF：层名按 style 写 `NOTE` / `GDT` / `DATUM`，文字高度取字高（下限 1 mm）；
- 画布：按层着色、字号随字高（6–16 px 夹取）、热态高亮；参数拖动/吸附/undo 逻辑不变。
