## E. 口径（R128 起沿用）

1. **预览要说全部**（R127）：预览的是受影响的对象集合，不是第一个。
2. **预览承诺的 before 必须取回**（R127）：提交前压栈，撤销回到的就是预览里的 before。
3. **一个数一个来源**（R127/84）：点径进表，调用点不许再写数字（有源码级断言）。
4. **逐行输入要能逐行给**（R127）：手打分隔符只是退路。
5. **契约变了同轮改锁契约的测试**（R127）。
6. **预览不改文档 / 预览与提交同源 / 目标只有一套语法 / 「空」也要判过期 / 历史行为优先**（R126）。
7. **页面给的就是库收的 / 默认值必须仍是历史行为 / 工具要能自证 / 校验要能真的红**（R125）。
8. **画不出来就不算标记 / 校验不依赖平台 / 谁说的算**（R124）。
9. **图要能重生成，也要能自证过期 / 数字要能看见 / 标记与状态条同源 / 陈旧标记要清 / 退化消息要修**（R123）。
10. **界面要追上库层 / GL 内容要单独取 / 工具要能离屏自检**（R122）；
    **挑选要有两个方向 / 目标从界面里点 / 锚点显式化 / 前提错了要更正**（R121）；
    **批量操作要能挑 / 只读就是只读 / 动作与目标都可按范围给 / 两条路径合一**（R120）。
11. **修复要保留意图 / 破坏性动作先说后做 / 作用域收到具体条目**（R119）；
    **诊断的下一步是修复 / 删除按值不按下标 / 冻结 = 把当前几何写成数**（R118）。
12. **诊断指到「哪一条」/ 体检常驻结构树 / Qt 对象必须有活着的 QApplication**（R117）；
    **标记能说话 / 体检覆盖所有按 ID 指向的结构 / 选择顺序是用户意图 / 不连续就拒绝**（R116）；
    **诊断落在几何上 / 一行坏数据不许让整张报告失效 / 模式的真相在会话 / 文件类型看内容**（R115）；
    **画出来的和能选中的是同一份几何 / 拾取偏好可预期**（R114）。
13. **一个概念一个数 / 局部化与计数同源 / 测量只读 / 多闭环体积断言求和 /
    再拉一次不复制已建体 / 尺寸单位三分**（R107–R112）。
