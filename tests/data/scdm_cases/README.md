Generated by driving the installed **ANSYS SpaceClaim 2019 R3** (`C:\Program Files\ANSYS Inc\v195\SCDM\SpaceClaim.exe`, 2019.3.38912) in batch with IronPython scripts (V19 scripting API). Every `.scdoc` here is written by SpaceClaim itself, so it is ground truth for `D:\training\caedecoder\scdocdecoding`.
Nothing in this folder may be written by the decoder repo, and nothing here writes into the repo.

## Naming convention

`<category>_<feature>_<NNN>_<keyparams>` — e.g. `01_primitives_cylinder_001_r10_h20_z`, `00_smoke_box_001_20x20x20`.

- `<category>` = folder name (`00_smoke` … `20_combo`); `<feature>` = short lowercase feature key (no underscores inside where avoidable); `NNN` = 3-digit variant number per feature; `<keyparams>` = short param tag (`r10`, `h20`, `40x20`, `0p5` for 0.5, `neg`, …). ASCII only, no spaces.
- Each case has three same-stem files in its category folder:
  - `<stem>.scdoc` – the SpaceClaim-saved document (ground truth)
  - `<stem>.py` – the IronPython script that built it (re-runnable)
  - `<stem>.json` – metadata: case_id, category, feature id (from `_inventory/feature_inventory.json`), params, SpaceClaim commands used, expected counts (bodies/faces/edges/vertices/volume, surface/curve types, doc entries), actual counts from SpaceClaim (result sentinel), SpaceClaim version, run command, generated_at (UTC+8)
- Optional per-batch files: `<category>_result.json` (sentinel of the last run), `<stem>_parser_report.json` (read-only scdocdecoding parser output).

## Modelling rules inside scripts

- Units: millimetres (`MM()`), document default units.
- **Name every body/component explicitly in English** (`RenameObject.Execute` / `SetName`), e.g. `Block_A`, `Boss`, `Plate` — the Chinese UI would otherwise auto-name them `实体`, `组件1`, which makes diffs locale-dependent.
- One `DocumentHelper.CreateNewDocument()` per case; save with `DocumentSave.Execute(<abs path>)`; close with `DocumentHelper.CloseDocument()` before the next case.
- Wrap each case in try/except; always write the result sentinel (success flag, counts, traceback).
- Select faces/edges by geometry (normal, centroid, radius), never by index.

## Running (batch / headless)

Proven in `00_smoke` (2026-09-26):

```
"C:\Program Files\ANSYS Inc\v195\SCDM\SpaceClaim.exe" /RunScript="<ABSOLUTE path>.py" /ExitAfterScript=True /Splash=False /Welcome=False /Headless=True
```

- Absolute script path is mandatory (relative paths are silently ignored).
- ~85 s startup + ~36 s exit per launch → batch many cases per launch (≤ ~25).
- SpaceClaim is effectively single-instance and the scdocdecoding test suite (`official_open` tests) also launches it: runners must refuse to start while another `SpaceClaim.exe` is running and must never kill a process they did not start.
- Reference runner: `00_smoke\00_smoke_run.ps1` (timeout 300 s, kill-after-sentinel 60 s, window-title capture, zip validation, optional read-only parser run with `PYTHONIOENCODING=utf-8`).
- Read-only parser check: `set PYTHONPATH=D:\training\caedecoder\scdocdecoding` & `python -B -m scdoc_parser <file.scdoc> -o <stem>_parser_report.json` (run from the case folder so nothing is written into the repo).

## Sheet metal

Sheet-metal cases are scripted (no GUI step): solid -> `ConvertToSheetMetal` -> `CreateMissingBends` / `Unfold` via the raw SheetMetal aspect.
